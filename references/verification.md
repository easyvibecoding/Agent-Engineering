## 檢查方式與範圍

使用本機 Python 標準函式庫逐項檢查檔案契約、題號、連結／自訂錨點及 PNG header；使用系統 curl 檢查來源與取得 CC BY 4.0 原始授權文字。未停用 TLS 驗證，也未修改全域憑證設定。

Git 提交前執行 git diff --cached --check；發布後另外核對遠端 visibility、main、檔案樹與關鍵 Markdown／圖片內容。遠端當前狀態仍以 GitHub 的實際讀回為準。
