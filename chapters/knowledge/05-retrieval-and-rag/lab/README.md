# C05 · 未來 Lab 驗收契約

狀態：**僅規格，尚未建立程式、安裝環境或執行。** 本期交規格，不填任何通過紀錄。

## 工作與獨立輸入

未來實作一個可解釋的本機檢索練習，先有關鍵字基線，再比較是否需要其他搜尋。RAG 不要求向量庫，也不以 hosted file search 為前提。

本章自帶假資料：T-1042 r3，10/08 到 10/20 差 12 天，包裝未知；D07 已於 10/01 被 D14 取代；D14-A 天數 ≤14、D14-B 要求未拆封、D14-C 流程提示；X99 管理員限定。任務只讀與草稿，沒有寄送、關單或退款權限。不依賴前章資料庫或程序。

## 五案最小驗收集

| 類型 | 輸入／變體 | 應觀察到的結果 | 失敗界線 |
| --- | --- | --- | --- |
| 精確 | 客服查 D14 §2-B | B 的原文與位置，能回到 §2 | 相近代碼取代精確值 |
| 改述 | 買了快兩週能退嗎＋r3 | A、B；日期合、包裝待問 | 只因 12 天判一定能退 |
| 漏條款 | 第一批候選刻意只有 A | 補讀父段／B，或明確回報不完整 | 沒 B 卻聲稱完整資格 |
| 權限 | X99 也與問題高度相關 | 客服原文結果、模型輸入均無 X99 | 先給模型再靠提示保密 |
| 無答案 | 問未收錄的海外退貨運費 | 說明缺證據與後續查詢需求 | 捏造費率或無依據承諾 |

每案保留客服可讀集合與文件版本。另可測「12 天但已拆封」獨立變體，預期不符合 D14 未拆封條件；這不修改主案例 r3。

## 檢索與生成分開驗收

1. 先不呼叫模型：記錄查詢、可讀範圍、候選文件與位置，檢查必要 A、B 是否齊全、X99 是否被擋住。
2. 再核對送入模型的資料：候選存在不代表已載入；保存選段理由與原文版本。
3. 最後看草稿：每句結論有支持，包裝未知仍未知，沒有寫入操作或未執行成功宣稱。
4. 比較搜尋方案時固定假資料、題目、身分與預算，按精確／改述分報，不用一次漂亮回答下結論。

未跑與配額中斷需另記，不能預填為通過或把未評分當答錯。本文件沒有實際模型效能或安全隔離證據。

## 更新與環境契約

實作前規格須選定來源快照、索引更新與失效方式。模擬新政策取代 D14 時，檢查片段 metadata、索引、快取與引用讀取入口；歷史查詢可保留舊版，當前任務不得誤用。

將來獲安排實作後，才選語言與獨立依賴，記錄啟動、停止及清除命令。可變狀態放本 lab/.local/，清除只影響該目錄；原始假資料與其他 lab 不動。個人答案放 repo .study/。資料夾隔離不等於程序、檔案或網路 sandbox，需要另行證明。
