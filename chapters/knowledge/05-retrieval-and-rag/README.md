# 05 · Retrieval 與 RAG

草稿寫到「一定可退」，你才看到政策下一行還有限制。這章從這個差點過度承諾的時刻開始，帶你找出：是沒讀到、沒交給模型，還是讀到了仍推錯。

<a id="這章要解決什麼"></a>

<a id="核心路線一次做懂"></a>

## 先從這裡開始

打開[正文](lesson.md)，沿四個場景讀到「把這次工作收好」。先不用記所有術語，也可以略過深挖的欄位表、搜尋選型與更新細節。

讀完先答 [Q01](exercises/README.md#c05-q01)，只畫出資料在哪裡漏掉。還有時間再做 Q03 與 Q05；卡住時，先回正文第三個場景，比直接打開解答更有機會找出自己的推論缺口。

需要協助才看[提示](exercises/hints.md)，修改後才看[參考解答](exercises/solutions.md)。也可把初答貼給 [Codex 教練](codex.md)，一次只談一個位置。

<a id="跳章入口"></a>

## 跳章也能接上

T-1042 r3 於 10/08 購買、10/20 申請，差 12 天，包裝未知。現行 D14 要求 ≤14 天且未拆封；舊 D07 已被取代。任務只讀與草稿，沒有寄送、關單或退款授權。這是[共同合成案例](../../../maps/course-story.md)。

前置只要知道「資料沒有寫，不代表事實已成立」與「缺資料可以停下詢問」。第 03 章工具、第 04 章循環能補這個背景；不用先跑 lab，也不用會向量資料庫。

<a id="深挖路線有需求才加機制"></a>

## 想再往下挖

你開始問「短政策到底要不要切段」時，讀[設計取捨](design-notes.md)。開始規畫自己的來源格式時，再看正文深挖與 Q04；Q02 比搜尋方案，Q06 只寫[未來 Lab 規格](lab/README.md)，目前不建立環境。

核心約 2–3 小時，可分成讀故事、做題、口答三段。7 天路線做 Q01、Q05；14 天路線加 Q03。個人答案放 .study/，保留第一版。[面試頁](interview.md)等你自答後再開。
