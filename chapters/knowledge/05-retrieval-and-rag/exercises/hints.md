# C05 · 分級提示

先寫自己的答案；每題先看第一級，修正後仍卡住才看第二級。

<a id="c05-q01"></a>

## C05-Q01

**第一級：**先沿資料移動方向想：候選有沒有、輸入有沒有、答案有沒有遵守。三個位置不是同一份清單。

**第二級：**在第一輪，問排序器是否看得到 B；第二輪先問誰把 B 刪掉。最後用兩個不同條件檢查「12 天」能證明多少。

[回題目](README.md#c05-q01)

<a id="c05-q02"></a>

## C05-Q02

**第一級：**比較「字號完全相同」和「意思近似」的需求，不要先宣布全部都用向量。

**第二級：**用同一資料快照和同一批人工標記題；分開記必要來源有沒有進候選與答案有沒有保留限制。商品碼題與改述題不要混成一個平均數。

[回題目](README.md#c05-q02)

<a id="c05-q03"></a>

## C05-Q03

**第一級：**日期計算沒錯，引用也可能存在；問題是引用是否支持「一定」這兩個字。

**第二級：**先補規則 B，再查個案是否未拆封。若 B 原已在輸入，責任就不能只歸給檢索；再設一題天數相同但包裝不同的測例。

[回題目](README.md#c05-q03)

<a id="c05-q04"></a>

## C05-Q04

**第一級：**客服要打開哪份哪版哪一節？B 的「上述」指哪一段？誰有權看原文？

**第二級：**想一遍資料從原檔到片段、索引、快取、模型輸入、引用開啟的路徑。新政策上線後，每一處都可能殘留舊值。

[回題目](README.md#c05-q04)

<a id="c05-q05"></a>

## C05-Q05

**第一級：**主答順序可用：問題 → 外部證據 → 仍有三種失敗 → 如何驗收。每步提一次本例資料。

**第二級：**追問時先定位候選、輸入或答案哪層失敗；小資料可以完整讀，規模與改述漏檢才是升級理由。

[回題目](README.md#c05-q05)

<a id="c05-q06"></a>

## C05-Q06

**第一級：**先不生成答案，也能檢查客服是否取到 A、B 且取不到 X99。

**第二級：**五案各寫「應有」「不應有」；查無規則案不能寫成沒有命中就判可退。把未跑、未評分與失敗分開，別預填通過。
