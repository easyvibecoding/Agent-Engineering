## 這章解決什麼

**昨天做過的工作，今天要怎麼接下去，又不被昨天的結論騙倒？**

你會替 T-1042 寫一份可接手的交接；重啟遇到 r4「已拆封」時，能說明哪些保留、哪些更新、何時停止。草稿完成與退款完成仍是兩件事。

## 具體前置與跳章背景

先能區分事實、推論、未知與授權；知道 D14 必須同時符合「≤14 天」和「未拆封」。不必會資料庫、不必跑過前章 lab。

本章資料：T-1042 r3，相差 12 天、拆封未知，只讀與草稿；今天 r4 補充已拆封。D14 仍適用，D07 已取代。完整見[共同案例](../../../maps/course-story.md)。

## 核心讀法：先能接手一件事

1. [正文](lesson.md)讀到恢復流程，約 45 分鐘：先理解五步案例，再回看名詞。

4. 用[面試追問](interview.md)和[Codex 卡](codex.md)修正一次，約 20 分鐘；留下六行交接作產物。

7 天路線只必做 Q01、Q05；沒有看完來源全文也可以先作答。

## 深挖讀法：記憶如何退出系統

再讀正文的生命週期、設計取捨第 3 項，完成 Q02、Q04、Q06，另排約 45–60 分鐘。重點是更正、到期、刪除及不同使用者不混用，不是保存越多越好。[未來 Lab](lab/README.md)只補驗收規格，不建立環境。
