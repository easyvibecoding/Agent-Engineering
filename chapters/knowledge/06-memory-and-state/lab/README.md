# C06 · 未來 Lab 規格

狀態：**僅規格，尚未建立程式、安裝環境或執行。**

## 任務與獨立輸入

設計從交接恢復的測試，不靠前章殘留資料。本章未來自帶合成 T-1042 r3、r4、D14、草稿 v1、兩位假使用者 A/B、到期偏好與刪除案例。

r3 為 12 天、拆封未知，只讀與草稿；r4 明確已拆封。D14 要求 ≤14 天且未拆封，D07 不適用。第三個中斷案另給定合成外部操作紀錄，僅練觀測，不授權真正執行或重做。

## 三個中斷點契約

| 中斷點 | 保存內容 | 恢復時觀測 | 預期決定 |
| --- | --- | --- | --- |
| 讀工單後 | 同案 ID、r3、D14、未知、權限 | 來源是否仍 r3，或已 r4 | r4 時更新條件；失敗保留現況未知 |
| 交草稿後 | 加入 v1 位置、草稿完成／業務待資料 | 產物可讀、當前工單版本 | 不重做已存在產物；必要時更正為 v2，不寄送 |
| 給定外部操作後 | 假操作 ID、目標、結果未知 | 假來源回傳完成／未完成／仍未知 | 分別標記；無授權不發重做要求 |

每案需留下「輸入→恢復讀回→版本比較→決定→產物位置／停止原因」。本機摘要不能代替外部讀回。外部執行與重試的完整規格由第 12 章展開。

## 加入會失敗的案例

1. 回傳 T-1043 r4：不得覆蓋 T-1042。
2. 工單來源暫時失敗：不得把 r3 摘要當今天已確認現況。
3. A 私有交接存在，B 查相同詞：不得取回 A 的私有資訊。
4. 偏好已到期：預設不再載入，必要時請求確認。
5. 偏好刪除後：原記錄、相關摘要與索引的檢索結果不得再次把它當有效偏好；備份依明示政策處理。

## 驗收產物

交一份六行交接、一張恢復決策表，以及每個案例的預期／實際欄位；尚未執行時實際欄一律填「未執行」。未來只有保留真實輸入、事件與結果後，才可判斷通過，不能用本題解答充當結果。

## 未來環境與權限

本 lab 可變狀態放 .local/；個人答案放 repo 的 .study/。依實作時選定語言記錄獨立依賴、啟動與清理方式，不共享其他 lab 狀態、不提交真實憑證。目錄隔離不是 sandbox，使用者資料隔離也需實際驗證。
