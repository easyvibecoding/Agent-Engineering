# C06 · 未來 Lab 規格

先從一個中斷點設計起：助理剛讀完 r3，程序就停了。下次啟動時，要看見什麼才知道可以接著做？

狀態：**只有規格，尚未建立程式、環境或執行。** 可以先寫預期結果，實際結果留「未執行」。

## 任務與獨立輸入

本章未來自帶合成 T-1042 r3／r4、D14、草稿 v1、假使用者 A/B 與偏好資料，不靠前章的程序或狀態。

r3 是 12 天、包裝未知；r4 補充已拆封。D14 要求 ≤14 天且未拆封，D07 已取代。本章只讀與草稿，不寄送、關單或退款。

## 三個中斷點契約

### 先做：讀工單後中斷

保存同案 ID、r3、D14、未知與權限。恢復時讀回目前版本；若變 r4，更新受影響條件。若讀取失敗，留下現況未知，不宣稱已確認。

### 再做：交草稿後中斷

加存 v1 位置與「草稿完成／業務待資料」。恢復先確認產物是否可讀，再比工單版本；已存在且仍適用的產物不需重做，必要時更正為 v2。不得把草稿完成當寄送完成。

### 深挖：給定外部操作紀錄後中斷

只提供結果未知的假操作紀錄，不授權執行或重做。保存假操作 ID 與目標，觀測假來源回傳完成、未完成或仍未知，再分別標記；沒有授權就不發重做要求。完整外部恢復策略由第 12 章展開。

## 加入會失敗的案例

先挑一個驗，寫完再加下一個：

- 回傳 T-1043 r4：不能覆蓋 T-1042。
- 來源暫時失敗：不能把 r3 標成今天已確認。
- B 查相同詞：取不到 A 私有交接。
- 偏好到期：不再預設載入，需要時重新確認。
- 偏好刪除：原記錄、摘要與索引不再回傳為有效偏好；備份依明示政策處理。

## 驗收產物

每案留同一條可查路徑：輸入 → 恢復讀回 → 比較 → 決定 → 產物位置或停止原因。

最後交六行交接與恢復決策表，逐案分開「預期」和「實際」。未來只有保留真實觀測後才能判通過，本機摘要或題解都不能代替結果。

## 未來環境與權限

可變狀態放本 lab 的 .local/，個人答案放 repo 的 .study/。實作安排後再記錄獨立依賴、啟動與清理方式，不共享其他 lab 狀態，不提交真實憑證。

目錄隔離不等於 sandbox；不同使用者資料也要實際驗證。推論優先走[訂閱路線](../../../../references/subscription-runtime.md)，能力、資格與共用配額另查。本輪不建立任何程式或執行證據。
