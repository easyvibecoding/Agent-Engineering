# C06 · Codex 協作卡

先貼自己的答案再使用卡片。預設只讀正文、設計取捨、題目；需要提示才開 hints.md，明確要求參考解答才開 solutions.md。這是教練流程，不建立 lab、不讀登入資料、不更改全域設定。

## 卡 1：把「記住」拆成四個決定

「我正在學 C06。先問我會保存 T-1042 哪些資料，等我回答，再依序追問：保存在哪、何時選入 context、怎樣確認仍有效、誰有權讀。一次只追一問，不直接給完整欄位表；若我說『加 memory』，請我改成具體讀寫動作。」

## 卡 2：用一個變體找推理缺口

「這是我的 Q03 答案：〔貼答案〕。先問我 r3 與 r4 哪些欄位沒變，等我答後再問哪些結論要變。最後追問：若 r4 其實屬 T-1043 呢？指出第一個不成立的推論，先讓我修正，不把三種變體一次講完。」

## 卡 3：審交接，不代寫交接

「這是我六行 T-1042 交接。請扮演下一輪接手者，先說你無法確定的第一件事，再問我補哪個欄位。依序檢查：目標／授權、來源／版本、已知／未知、產物／副作用、下一步／停止。不因我寫『已處理』就當成寄送成功。」

## 卡 4：面試與反例

「用 Q05 面試我，先給兩分鐘自答。依我的弱點從這些題目選一題追問：有檔案為什麼模型看不到？RAM 儲存重啟後呢？A 的資料如何防 B 取到？刪掉原記錄後摘要還在呢？最後給一項可驗收的改進，不把流暢當正確。」

## 卡 5：只審未來 Lab 規格

「我只寫 Q06 規格。先找一個無法驗收的句子，再要求我補輸入、觀測與預期結果。外部操作結果未知時，不安排未授權重做。不寫程式、不安裝依賴。請把已設計與尚未執行分開回報。」

教練可使用訂閱可選模型；是否答對依本章資料與判分，不由模型名稱保證。本卡不自動切模型。
