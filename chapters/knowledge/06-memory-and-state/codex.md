# C06 · Codex 協作卡

先選一張卡，貼上自己的答案。讓 Codex 一次只追問一件事，等你修正再往下走。

預設只讀正文、設計取捨與題目；需要提示才讀 hints.md，明確要求解答才讀 solutions.md。不建立 lab、不讀登入資料、不改全域設定。

## 卡 1：把「記住」拆成四個決定

「我正在學 C06。先問我：昨天的交接有保存，但這輪沒載入，模型知道什麼？等我回答，再只問一個下一步問題。逐步檢查保存、載入、現況有效性與讀取權限；不要一次給我完整表格。」

## 卡 2：用一個變體找推理缺口

「這是我的 Q03 答案：〔貼答案〕。先找第一個不成立的推論，問我依據在哪裡。等我修正後，再問 r3→r4 有哪個欄位不變。不要直接重述完整解答。」

## 卡 3：審交接，不代寫交接

「這是我的六行交接：〔貼答案〕。你是下一輪接手者，先問你最無法確定的一件事，等我補完再繼續。必要時檢查目標、授權、來源、未知、產物與下一步；不要因為我說『已處理』就認定已寄送。」

## 卡 4：面試與反例

「先用 Q05 問我，等兩分鐘口答後再追一題。依我的答案選 RAM 重啟、B 讀 A 資料，或刪除後摘要仍在其中一題。最後只給我一項可驗收的改進，讓我重答。」

## 卡 5：只審未來 Lab 規格

「這是我的 Q06 規格。先找一句無法觀測的敘述，問我要看哪個輸入或結果才可判定。等我補完再看下一項。外部結果未知時，不安排未授權重做；不寫程式、不安裝依賴。」

若要暫停，請 Codex 留一句：目前已說清＿＿；還沒說清＿＿；下次先追問＿＿。模型名稱不保證正確，本卡也不自動切模型。
