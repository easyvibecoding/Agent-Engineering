# C06 · 題目

版本：2026-10-21。本章案例均為合成，基礎條件：T-1042 r3、12 天、D14 要求 ≤14 天且未拆封；拆封未知，只讀與草稿。r4 已拆封只在明示變體使用。

14 天必做 Q01、Q03、Q05；7 天必做 Q01、Q05。先自答，需要才開提示與解答，個人答案放 .study/。

## C06-Q01 · 概念重建

把下列資料分成「當輪輸入」「本案狀態／checkpoint」「可跨任務資訊」：這輪載入的 D14、T-1042 待問拆封、昨天草稿 v1 位置、客服 A 明確確認的短答偏好、D14 原文位置。

**交付與判分：**交一張表，逐項寫來源、適用對象、何時應更新或停用；說明同一筆資料為何可同時被保存與載入。

## C06-Q02 · 方案比較

交接寫「草稿已交，但不知道有沒有寄送」。本題沒有新增寄送授權。哪些內容只讀摘要即可？哪些結論要回查原始／操作紀錄？若暫時查不到紀錄怎麼辦？

**交付與判分：**分成保存、載入、查證三欄；列出確認寄送所需證據，以及證據缺少時的狀態與禁止動作。

## C06-Q03 · 軌跡診斷

昨日 r3：12 天、拆封未知、草稿 v1 已交。今日可信工單來源回傳 T-1042 r4：已拆封。助理載入舊摘要後說「已符合 D14，可以退」。

**交付與判分：**標出兩個錯誤推論；給出更新前後四個欄位（版本、包裝、判斷、下一步），並寫兩句更正草稿。權限仍只有讀取與草稿。

## C06-Q04 · 架構設計

## C06-Q05 · 面試口答

## C06-Q06 · 未來 Lab 規格

只寫恢復測試規格，涵蓋讀工單後、交草稿後、外部操作後中斷。前兩案使用本章只讀任務；第三案僅給定合成操作紀錄，其結果未知，不賦予執行或重做授權。

**交付與判分：**每案列保存內容、重啟讀回、禁止重做、預期產物與驗收證據；再加不同使用者、過期偏好、刪除後檢索三項測試。不寫程式。
