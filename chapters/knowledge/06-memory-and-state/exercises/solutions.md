# C06 · 參考解答

以下是合成案例的推理範例，不是唯一措辭，也不是已執行證據。每題三項各 0–2 分：0 缺少或相反，1 有概念但缺資料，2 能以題目資料支持判斷。

<a id="c06-q01"></a>

## C06-Q01

當輪載入 D14 是 context；T-1042 待問拆封與草稿位置屬此案 state，checkpoint 保存該時點。A 確認短答偏好可在 A 範圍重用。D14 原文由政策來源維護，交接保留版本與位置。保存的資料被選入這輪後也會出現在 context，分類並非互斥容器。r4 回覆使包裝狀態需更新；政策改版需重核適用性；偏好更正、到期或刪除後應停用。

**判分：**範圍與身份正確；保存與載入分開；來源與更新條件明確，各 0–2 分。

**可接受替代：**可用事件紀錄加查詢視圖代替單一 checkpoint，但需能重建同樣的目前狀態。

## C06-Q02

保存草稿位置、來源、待查寄送狀態；當輪先載入短交接。若要宣稱已寄送，回查對應工單、收件對象、操作 ID 與實際結果。只看到「產生草稿」不支持「已寄送」。查不到時標寄送未確認，停止寄送相關推論；本題沒有寄送授權，不能藉重試查證之名寄出。

**判分：**保存／載入／查證三層；具體操作證據；未知不當成成功或未發生，各 0–2 分。

**可接受替代：**可讀可信郵件／工單稽核紀錄；不限定某種工具名稱。

## C06-Q03

錯誤一：r3 的日期符合被擴張成整體符合，忽略拆封未知。錯誤二：已有同案可信 r4，卻仍讓舊摘要當現況。版本 r3→r4；包裝 unknown→已拆封；判斷等待資料→未符合 D14 未拆封條件；下一步查回覆→更正草稿 v2。保留 r3 與 v1 歷史並標取代原因。草稿：「依 D14，12 天符合天數限制；r4 回覆已拆封，因此未符合未拆封條件。本次為更正草稿，尚未寄送、關單或退款。」

**判分：**兩種錯誤均指出；四欄更新及來源；草稿保留權限與條件，各 0–2 分。

**可接受替代：**可把業務狀態寫成需人工後續處理，只要不聲稱已退款或允許模型自行改店規。

## C06-Q04

六行可為：①T-1042，判斷與草稿。②僅讀取，禁止寄送／關單／退款。③工單 r3、D14 條款位置。④日期 12 天，拆封 unknown。⑤草稿 v1 位置，本案例明示無外部寫入。⑥草稿完成、業務待資料；下輪先查新回覆。恢復 r4 時更新受影響條件與草稿；讀取失敗保留現況未知並報阻礙；T-1043 不可覆蓋 T-1042，重新取得正確目標前停止。

**判分：**六行含可接續欄位；三分支有不同決定；不把歷史當現況，各 0–2 分。

**可接受替代：**可用表格六列或結構化欄位表達，不依字面恰好六行判定理解。

## C06-Q05

Context 是這輪桌面；store 是可再找資料的櫃子；checkpoint 是某件事停下來的交班單。存進櫃子不會自動送到桌面，資料也不因保存就永遠有效。昨天 r3 未知，今天 r4 已拆封，應保留歷史、更新目前判斷。資料櫃可能只在 RAM，重啟不保證保留，更不等於模型訓練。驗收可用 B 查同關鍵字，確認取不到 A 私有交接。

**判分：**三者責任可區分；r3→r4 修正具體；類比限制與隔離驗收，各 0–2 分。

**可接受替代：**可不用比喻，但須同樣說清保存、選取、現況確認。

## C06-Q06

讀後中斷：保存 r3 與來源，重啟查是否 r4，再更新判斷。草稿後中斷：加存 v1 位置與業務待辦，不能把交付草稿當寄送。外部操作後中斷：保留給定操作 ID、目標與結果未知，讀回操作／目標狀態，無授權不重做；本章僅設計觀測，不發出外部操作。補測 B 不能讀 A、到期偏好不再預設載入、刪除後檢索與摘要不回傳。每案保留輸入版本、恢復觀測、決策及輸出位置作未來驗收證據，現階段一律未執行。

**判分：**三中斷點可觀測；未知操作不盲重做；生命週期與隔離覆蓋，各 0–2 分。

**可接受替代：**可把副作用觀測案移到第 12 章實作，但本規格仍需標出未知與交接要求。
