# C06 · 分級提示

每題先看第一級；仍卡住才看第二級。請先保留自己的第一版答案。

<a id="c06-q01"></a>

## C06-Q01

1. 先區分「它在說哪件事」與「現在模型看得到嗎」。
2. 短答偏好要有確認與使用者範圍；D14 原文位置不是有效性的永久保證。

[回題目](README.md#c06-q01)

<a id="c06-q02"></a>

## C06-Q02

1. 摘要足以提醒你有一個待查事項，不足以證明寄送發生。
2. 找目標、操作 ID、實際結果；證據缺少時不能重寄，也不能說肯定沒寄。

[回題目](README.md#c06-q02)

<a id="c06-q03"></a>

## C06-Q03

1. 舊 r3 本來就沒有支持「完整符合」。
2. r4 改的是包裝條件；日期 12 天仍成立，舊草稿應標過期，不是偷偷覆蓋歷史。

[回題目](README.md#c06-q03)

<a id="c06-q04"></a>

## C06-Q04

1. 接手者先問：哪一案？我可做什麼？第一步是什麼？
2. 別案不能更新本案；讀取失敗也不等於沒有新資料。

[回題目](README.md#c06-q04)

<a id="c06-q05"></a>

## C06-Q05

1. 同一份紙可以留在櫃子，也可以被選到桌面；兩個動作分開。
2. 不要把櫃子說成模型權重；用另一使用者查不到 A 私有個案作驗收。

[回題目](README.md#c06-q05)

<a id="c06-q06"></a>

## C06-Q06

1. 中斷點不同，重做風險不同；已交草稿不等於已寄送。
2. 外部結果未知先查；刪除測試還需看摘要或索引是否帶回舊資料。

[回題目](README.md#c06-q06)
