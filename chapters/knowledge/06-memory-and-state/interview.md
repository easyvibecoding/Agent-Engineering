# C06 · 面試與追問

先試著口答：「隔天重啟助理，有交接檔，為什麼還可能答錯？」給自己兩分鐘，不急著背名詞。

## 主問題與短答骨架

第一句先說需求：接續同一件工作，但事實可能已更新。

接著用三個動作解釋責任：把記錄保存、挑進本輪輸入、核對現在是否仍適用。說到這裡，再帶入 context、store、checkpoint，名詞就有落點。

最後用 r3→r4 說明一次修正，並補驗收方法。若只說「加入 memory」，還沒回答哪些記錄能相信。

想先組織而不看示範，可填：我要接續＿＿；保留＿＿；重查＿＿；遇到未知則＿＿。

## 追問順序

一次只選一問，答完再追，不用六題連發。

1. 有全部聊天，為什麼還需要交接？先談目前狀態與歷史訊息的差別。
2. 哪些需要重查？先選一個會改變下一步的事實。
3. r4 比 r3 新，就一定可信嗎？補上同案與來源檢查。
4. 交草稿後重啟，要再寄一次嗎？辨認產物與副作用，也核對授權。
5. B 查同樣關鍵字，怎麼避免拿到 A 資料？說可觀察的隔離測試。
6. 刪了偏好但摘要還在，算完成嗎？指出仍需處理的副本。

## 常見弱答怎麼補

「用向量庫記住」可以改成：「先確定要保存的資訊、身份範圍與來源，再定義何時載入。」檢索相似不保證資料有效。

「重啟全部重跑」可以改成：「先查哪些已完成、哪些未知，只重做可重做的部分。」外部操作不應跟著全部再來一次。

「checkpoint 保證正確」可以改成：「它記錄當時進度，仍要核對新版本與外部現況。」

## 自評

需求、具體資料、取捨／失敗、可觀察驗收，各 0–2 分。0 是缺少，1 是只有概念，2 是能以本例支持。

一次挑最低的一項修正即可。分數是練習用，不是真實面試成果。按需看 [Q05 解答](exercises/solutions.md#c06-q05)；本章 lab 未實作，口答不要說成曾部署。
