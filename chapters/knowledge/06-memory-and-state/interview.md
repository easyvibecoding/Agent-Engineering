# C06 · 面試與追問

## 主問題

用工作桌、資料櫃與進度快照解釋 context、memory、checkpoint；補一句類比的限制。

先口答兩分鐘：用一句話定義問題，再引用本章資料說明決策、失敗與驗收。不要逐字背參考解答。

## 面試官可以怎麼追

- 方案選擇：何時只載入摘要，何時回看原始紀錄？請用『草稿已交但不知道有沒有寄送』作例子。
- 出錯定位：變體：昨天 r3 摘要寫拆封未知；今天 r4 客戶回覆已拆封。助理卻沿用舊摘要說可以退。如何修正進度與答案？
- 設計落地：寫一份六行 T-1042 交接，讓另一輪不必重讀全部對話，仍能安全接續。

## 自評

每項 0–2 分：是否答到需求；是否引用具體資料；是否說明取捨與限制；是否提出可觀察驗收。0 為缺少，1 為只有概念，2 為能用案例說明。分數只供練習，不代表已通過真實面試。

本題重點：三者各有作用；指出不保證自動載入或正確。
