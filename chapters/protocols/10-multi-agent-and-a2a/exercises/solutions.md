## C10-Q01

主助理只取政策筆記時，工具式委派讓主助理收結果後繼續；三輪追問可考慮 handoff，須明定接手範圍與何時退回。A2A 解決跨系統交換訊息與產物，並不決定誰最後整合；可承載工具式委派或交接。此例由總負責者驗收 D14 條款及來源，交接變體也要指派最後交付者。

**分點判分：**

- 分清結果呼叫與互動接手。
- 分清控制與通訊層。
- 明定驗收者和適用條件。

**可接受替代：**可採不同欄位名稱或交接架構；要保留目標、版本、權限與可驗收責任，不能猜補未知。

## C10-Q02

串行 25+30+8=63 秒；理想並行 max(25,30)+8=38 秒，少等 25 秒約為串行的 39.7%。全隊輸入 4,000+4,000+2,000=10,000，較 6,000 多 4,000。這只比較合成輸入量，不推導費用。啟動與共享額度排隊可能拉長關鍵路徑，來源缺漏返工也可能吞掉收益。若 A/B 有依賴，38 秒前提即不成立。

**分點判分：**

- 兩式與數字正確。
- 全隊量計算正確且不冒充費用。
- 明列理想假設與兩個成本因素。

**可接受替代：**可選單 Agent 不委派，但仍需交出相同可核對產物與資源比較設計。

## C10-Q03

暫停交付並保留稿件與事件。已知兩 worker 宣告結束、主稿被覆蓋；未知實際查過來源與是否有業務寫入。A 的 7 天與 D14 不符，B 的 T-1043 與目標不符。要求 A 補 D14 生效日、完整兩條件及來源；B 補 T-1042 r3 的日期、拆封未知及來源。兩人改交獨立筆記，只有總負責者整合主稿。驗收後應產生「12 天符合、拆封待確認」草稿；無操作證據不能說已拒絕或替使用者執行反向修改。

**分點判分：**

- 找出政策、目標與覆寫三錯。
- 狀態與實際副作用分開。
- 補查內容及整合順序具體。
- ownership 與完成標準明確。

**可接受替代：**可採不同欄位名稱或交接架構；要保留目標、版本、權限與可驗收責任，不能猜補未知。

## C10-Q04

委派含 task_id、目標 T-1042、預期 r3、讀取範圍、禁止寫入、獨立筆記位置及驗收者。回報至少含 task_id、實際 ID/revision、購買和申請日期、拆封狀態、來源位置、未知或失敗、實際副作用。成功是能核對的讀取產物；未知欄位應保留而非猜測。T-1043 拒收並精確補查；r4 則報版本不符，由總負責者依使用者問題決定固定 r3 或更新分析。兩者都不准自行寫工單。

**分點判分：**

- 精確目標與限制。
- 至少五個可核對欄位。
- 成功及停止不等於業務核准。
- 兩種變體處理且不偽裝版本。

**可接受替代：**可採不同欄位名稱或交接架構；要保留目標、版本、權限與可驗收責任，不能猜補未知。

## C10-Q05

我會先以單 Agent 作對照，只有政策與工單閱讀夠長且獨立才拆。若兩人共寫主稿，A 舊版政策可能被 B 錯工單覆蓋，總負責者只看 completed 就交出流暢錯答。改為獨立筆記、核對 ID/版本與完整條件、由一人整合。比較固定題目、資料、權限及全隊預算，量條件完整率、全程可用產物時間、全隊輸入輸出和工具資源；保留返工與未完成案。若品質未達標或整合耗時大於收益，就留在單 Agent。

**分點判分：**

- 因果鏈落到案例。
- 對依賴與責任有選擇。
- 品質與全隊資源比較公平。
- 有換回方案的條件。

**可接受替代：**可選單 Agent 不委派，但仍需交出相同可核對產物與資源比較設計。

## C10-Q06

固定資料快照、工具權限、模型設定及全隊預算，單 Agent 與 coordinator+A+B 都用同一批案例。品質看 ID/版本正確、D14 兩條件完整、未知及權限誠實；資源看從開始到可用產物的全程時間，以及整隊推論/工具用量。事件含 run_id、task_id、角色、目標、版本、開始/結束、狀態、來源、產物與拒收原因。預算含整合與返工，達上限記未完成；錯 ID/缺條款不能當通過，worker 失敗也保留。所有預期都標設計，實際數字與環境邊界待後續實作驗證。

**分點判分：**

- 三品質兩資源及可比條件。
- 整隊預算與停止規則。
- 異常案例有預期與事件。
- 沒有把規格冒充執行結果。

**可接受替代：**可選單 Agent 不委派，但仍需交出相同可核對產物與資源比較設計。
