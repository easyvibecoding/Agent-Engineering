# C10 · 分級提示

先自答；第一級只指出方向，仍卡住才看第二級。

<a id="c10-q01"></a>

## C10-Q01

1. 先問是取一份結果，還是接手一段對話。
2. 把控制方式與跨系統通訊分成兩欄；兩欄可以同時存在。

[回題目](README.md#c10-q01)

<a id="c10-q02"></a>

## C10-Q02

1. 並行的等待先取最慢分支，整合仍要在後面。
2. 把全程延遲與各 Agent 資源合計分開；不要拿每位 worker 的預算當全隊預算。

[回題目](README.md#c10-q02)

<a id="c10-q03"></a>

## C10-Q03

1. 先別選較新的那份；兩份各違反哪個固定輸入？
2. 狀態、內容、實際副作用分開。修正壞分支，不一定全部重跑。

[回題目](README.md#c10-q03)

<a id="c10-q04"></a>

## C10-Q04

1. 把精確 ID、預期版本、禁止動作放在委派，不只放事後檢查。
2. 不要要求 worker 把 r4 偽裝成 r3；需要決定快照分析還是目前狀態。

[回題目](README.md#c10-q04)

<a id="c10-q05"></a>

## C10-Q05

1. 不要只列「成本高、溝通難」，說明哪個步驟讓結果變壞。
2. 檢查全隊總預算、全程時間、失敗保留；只比較最快 worker 會誤導。

[回題目](README.md#c10-q05)

<a id="c10-q06"></a>

## C10-Q06

1. 測試不只要順利的 A/B；錯 ID 和缺來源需被拒收，失敗要留在報告。
2. 讓限制適用整隊，包含總負責者與重試；到上限就交未完成狀態。

[回題目](README.md#c10-q06)
