## 這章要解決什麼

**多找幾個 Agent，真的會更快、更可靠嗎？**

上一章共用工具與方法。這章只在工作能清楚拆分時討論分工；不預設一定要多 Agent。

本章交付：兩份可回查的獨立產物，加一份由總負責者整合的草稿。上表時間只是合成算例，並非模型效能實測。
