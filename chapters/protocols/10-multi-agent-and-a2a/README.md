# 10 · 多 Agent、協調與 A2A

章節 ID：C10 · 修訂：2026-10-21 · 核心約 2–3 小時 · Lab 僅規格。

## 本章要交出什麼

用兩份獨立證據筆記，整合一份條件式客服草稿。你要能回答「哪些能同時做、誰最後檢查、哪個結果應拒收」，再決定多 Agent 是否值得。

T-1042 r3 相隔 12 天、拆封未知；D14 要求 ≤14 天且未拆封。A 查政策、B 查工單，總負責者寫草稿。全程只讀，沒有寄送、關單與退款授權。完整假資料見[共同案例](../../../maps/course-story.md)。

## 前置能力與跳章入口

先會分開「工具要求、工具實際結果、最後說法」（第 03 章），以及「資料版本與記憶摘要」（第 06 章）。第 09 章幫你分清工具、方法和權限。跳章者讀正文欄位表即可補齊本題，不需要前章環境。

## 核心讀法：約 2–3 小時

1. [正文](lesson.md)讀到「停止與交付」：畫 A/B 依賴並寫委派與回報各一份，約 40 分鐘。
2. [設計取捨](design-notes.md)前兩項：說出何時不分工、何時不共編，約 20 分鐘。
3. [Q01、Q03、Q05](exercises/README.md)：先自答與口答，約 45 分鐘。
4. 用[Codex 協作卡](codex.md)追問，再看自己需要的[提示](exercises/hints.md)或[解答](exercises/solutions.md)，約 30 分鐘。
5. [面試卡](interview.md)重答兩分鐘，列出仍不確定之處，約 15 分鐘。

## 深挖讀法：另排時間

讀正文後半的版本處理、三種架構選擇、資源算例；做 Q02、Q04、Q06。可以先完成核心再回來，不必一天內讀完所有來源。Q06 和 [Lab](lab/README.md)都只交規格。

## 完成判斷

能指出一條真正可並行的分支、一條必須等待的依賴；能拒收錯 ID／版本或缺條款產物；能用全隊資源與全程時間比較方案。只說「多 Agent 會更好」仍不夠。
