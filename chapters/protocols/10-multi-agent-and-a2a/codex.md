# C10 · Codex 協作卡

選一張就好，貼卡時附上自己的答案；回來續讀時也可附「我已決定什麼、仍卡在哪裡」。預設只讀本章正文、設計取捨和題目；先自答，要求提示才讀 hints.md、要求解答才讀 solutions.md。只討論規格，不啟動 Agent 或建立程式。

## 卡 1：先拆依賴，再談委派

「請當 C10 教練。我先列 A 查政策、B 讀工單、C 判斷、D 寫草稿。請先等我畫依賴，再依序問：哪一支輸入已知？誰要等誰？誰能寫主稿？每次只追問一題，讓我修正後才往下；不要直接替我畫答案。」

## 卡 2：驗收兩份結果

「這是我的 Q03 答案。先請我區分 worker 狀態、產物內容、實際業務副作用。再問 A 哪裡不符、B 哪裡不符、先補哪一支、由誰整合。指出第一個沒有證據的推論即可，讓我自己重寫；未經要求不開解答。」

## 卡 3：用數字戳破口號

「我說多 Agent 較快，請用 Q02 讓我自己算等待時間，不先報正確數字，再追問全隊輸入量、啟動排隊、返工和總預算。若我把 token 數當訂閱價格，請要求我說明缺少哪些資料。不要假裝合成數字是模型實測。」

## 卡 4：兩分鐘面試與規格審閱

「先讓我口答 Q05 兩分鐘，再從一條因果鏈開始追問。等我修正後，才問 ownership；版本變更與換回單 Agent 留到我準備好再問。最後看我的 Q06 規格：哪個失敗會被保留？怎樣停止？預算是否含整隊？只評我寫出的內容，不替我實作或聲稱已跑通。」

評分看具體輸入、推理、責任與可觀察結果；文筆流暢與模型名稱都不能替代驗收。這些卡不修改模型、全域設定或登入資訊。
