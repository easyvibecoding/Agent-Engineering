# 09 · MCP、Skills 與工具探索

章節 ID：C09 · 修訂 2026-10-21 · 核心約 2–3 小時 · Lab 僅規格。

**要解的問題：專案規則、工作方法、真正的工具與本次授權，各放哪裡？**

第 08 章已拆開推論與工具執行。本章加入跨應用共用能力：同一個店規服務讓不同 host 使用，同時保留各自的任務範圍與資料權限。

## 具體前置與跳章入口

能說出「模型要求呼叫」和「工具已執行」的差別，知道工具有輸入、結果與錯誤即可。若還不清楚，回查[第 03 章](../../agent-core/03-tool-contracts/README.md)的契約概念；不必先啟動任何環境。

合成案例：T-1042 r3 相隔 12 天；D14 要求≤14 天且未拆封，工單拆封未知。只准讀取與草稿。團隊有 300 個工具，也有判斷方法包；本章要避免把「有方法」當成「有權讀所有案件」。見[共同案例](../../../maps/course-story.md)。

## 核心讀法：完成一條可驗收路徑

1. [正文](lesson.md)讀到「讀懂失敗，才知道下一步」，約 40 分鐘：畫 host/client/server，走一次 300→8→2 探索。
2. [設計取捨](design-notes.md)讀前兩項，約 20 分鐘：說明直接函式何時足夠、方法何時值得封裝。
3. [Q01、Q03、Q05](exercises/README.md)先自答，約 45 分鐘。7 天路線先做 Q01、Q05。
4. 用[Codex 協作卡](codex.md)或[面試追問](interview.md)口答與修正，約 25 分鐘。
5. 回想並寫配置表，約 10 分鐘；卡住才讀[提示](exercises/hints.md)，需要才開[解答](exercises/solutions.md)。

## 深挖讀法：另外安排 45–75 分鐘

讀正文的探索驗收與版本相容、設計取捨第 3 項，完成 Q02、Q04；Q06 只寫[未來 Lab 契約](lab/README.md)。官方來源先看角色和適用版本，不必第一輪抄完整封包。

## 本章交付與自我檢查

交一張配置表：AGENTS.md 放什麼、Skill 放什麼、工具由誰提供、誰拒絕越權。再用一句話交代 T-1042 的結果：日期符合、拆封未知、只完成詢問草稿。

能說清「列舉成功」「本次呼叫獲准」「結果足以支持結論」三者差別，才算掌握；只背 MCP 名稱還不夠。
