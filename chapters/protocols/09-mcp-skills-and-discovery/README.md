## 先這樣讀就好

讀正文前四個場景，約 40 分鐘。遇到「停 20 秒」先選一個答案，不用開其他文件找標準答案。完整角色表、協定分類、版本與擴充都可以先略過。

接著做[Q01、Q03、Q05](exercises/README.md)，約 45 分鐘；7 天路線先做 Q01、Q05。先留自己的答案，卡住再按需讀[提示](exercises/hints.md)，要求參考解答時才看[解答](exercises/solutions.md)。

用[Codex 協作卡](codex.md)一次問一個地方，再花 20–30 分鐘讀[設計取捨](design-notes.md)前兩項、修自己的配置圖。最後用[面試追問](interview.md)重說一次。
