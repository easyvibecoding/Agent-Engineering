# C09 · Codex 協作卡

先挑一張卡，不用一次貼完。每次只讓 Codex 問一件事，等你自答再回饋。

共同約定：先只讀正文、設計取捨與題目；你要求提示才讀 hints.md，要求參考解答才讀 solutions.md。沒有建立 lab、安裝或修改設定的任務。

## 對話 1：先畫責任，再給術語

「我貼自己的配置圖。請先只問我：我正在操作的是哪個應用？等我答，再問要求由誰送出，最後才問誰限制案件存取。不要先給全部術語；我說不清楚時，請我回正文場景 3 找一個動作。」

## 對話 2：用一次失敗找推論缺口

「用 Q03 檢查我。先問事件①證明了什麼，等我答；再問事件②。每次只指出一個缺口，請我自己改一行。不要直接解釋後面全部錯誤，也不要先開解答。」

## 對話 3：審探索設計，而不是稱讚工具數下降

「我貼 Q04 的探索圖。先讓我走正常路，接著只加入『同名工具連到測試店』這個變體。等我修完，才選分類缺漏、舊契約、撤權中的下一個。若我只說節省 token，先追問一個正確性驗收，不替我編效能數字。」

## 對話 4：逐句修口答

「先等我說 Q05 一分鐘。只挑一句最抽象的話，問我：在 T-1042 裡，這句對應哪個具體動作？等我重答，再補失敗分支。最後才依需求、責任、失敗及驗收評分；不把合成例子當我的部署經歷。」

## 對話 5：只審未來 Lab 契約

「我先交 Q06 的列舉成功與無權限兩列。請先檢查一列能證明什麼，等我修完才看下一列。再提醒我補齊六種情況；不建程式、不啟動服務、不讀登入檔。」

若教練說某 runtime 支援所有 MCP 功能，先請它給目前第一方來源與適用範圍。模型回答本身也要驗收，不能只因名稱或語氣就採信。

**接讀便條：**我已能回答＿＿；還想被追問＿＿；下次使用對話＿＿。
