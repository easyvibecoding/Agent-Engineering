# C09 · 面試與追問

## 主問題

用客服例子說明 MCP 和 Skill 的差別，並舉一個兩者搭配的做法。

先口答兩分鐘：用一句話定義問題，再引用本章資料說明決策、失敗與驗收。不要逐字背參考解答。

## 面試官可以怎麼追

- 方案選擇：『本 repo 不代答』『先查日期再拆封』『讀 T-1042』各放哪裡？若只有方法但沒有工具會怎樣？
- 出錯定位：變體：server 能列出 read_ticket，但呼叫 T-1042 回無權限；Skill 又寫『必須讀到』。你應查什麼、做什麼？
- 設計落地：為 300 個工具畫兩階段探索：如何縮小選單，以及執行前仍需檢查什麼？

## 自評

每項 0–2 分：是否答到需求；是否引用具體資料；是否說明取捨與限制；是否提出可觀察驗收。0 為缺少，1 為只有概念，2 為能用案例說明。分數只供練習，不代表已通過真實面試。

本題重點：溝通與方法分開；附真實執行限制。

先自評，再按需看[Q05 參考解答](exercises/solutions.md#c09-q05)。涉及執行成果時，分開說已設計、已實作、已測試；本 repo 的 lab 尚未實作。
