# C09 · 未來 Lab 規格

狀態：**僅規格，尚未建立程式、依賴、環境或實際執行證據。**

## 獨立輸入與邊界

未來本機 lab 自帶 T-1042 r3、D14 與六組服務情況，不使用前章資料庫、程序或 token。工單日期 2026-10-08／10-20 差 12 天；拆封未知，D14 要求≤14 天且未拆封。只讀與草稿，不提供關單或退款能力。

300 工具的目錄可用純合成描述；不必真的連 300 個外部服務。先驗探索與契約，再決定是否需要模型參與，不能以模型口述冒充協定執行。

## 必交產物

- 配置表：持續規則、可重用方法、工具能力、執行授權各由誰負責。
- 相容表：host/client/server 套件版本、共同協定版本、必要 tools/resources/prompts、選用擴充。
- 六列測例矩陣：假輸入、預期、實際觀察、下一步、不能宣稱的結果；目前實際觀察全部標未執行。
- 一份條件式草稿：日期符合、拆封未知，未寄送、關單或退款。

## 六種驗收契約

| 測例 | 假條件 | 未來要讀回什麼 | 下一步與停止 |
| --- | --- | --- | --- |
| L01 列舉成功 | 服務提供 read_ticket 描述 | 名稱、來源 server 與契約 | 接著檢查本次呼叫，不能標工單已讀 |
| L02 讀取成功 | 客服 A 可讀 T-1042 | id、r3、日期、unknown、D14 版本與條款 | 草稿條件式結束，業務等待補資料 |
| L03 無權限 | 客服 A 無此案權限 | 明確拒絕，沒有工單欄位 | 核對身分與 scope；不能擴查其他案補答案 |
| L04 版本不合 | 雙方無共同協定版本 | 雙方版本及不相容觀察 | 停止該能力，交接相容問題 |
| L05 工具缺少 | 只有工單，無店規能力 | 可用能力清單與缺少項 | 受控找替代；沒有就保留政策缺口 |
| L06 服務不可用 | 無法取得服務結果 | 錯誤、有限嘗試與未取得資料 | 預先定義次數／時間上限，到限即停 |

反例驗收：L03 不能因 Skill 寫「必須讀到」就改用更大權限；L05 不能以訓練記憶中的 7 天規則充當 D14。另測列舉後撤權時，實際呼叫仍須被拒絕。

## 證據如何記

未來每筆保留 case_id、能力來源、目標、契約版本、候選要求、實際結果與拒絕原因。不記真實 token；不要把模型最終文字當成服務成功的唯一證據。

L02 的成功只代表本測例讀取與草稿通過；不能推出所有 runtime 支援所有 MCP 擴充，也不能推出真實商店已處理退貨。

## 環境與清除契約

後續獲安排實作時，才選語言、獨立依賴及啟停方式，記錄服務程序與檔案／網路範圍。可變狀態放本目錄 .local/；個人答案放 repo 的 .study/；憑證不進 repo。不修改全域 Codex 設定。

目錄隔離不代表 sandbox；應另驗證程序、檔案與網路邊界。若需模型，優先採可用訂閱路線並另查資格與共用配額，不依賴 hosted MCP、不自動轉 API key。
