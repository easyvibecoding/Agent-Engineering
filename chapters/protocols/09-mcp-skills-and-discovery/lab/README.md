# C09 · 未來獨立 Lab 契約

狀態：**規格完成，尚未實作**。本期沒有程式、依賴 manifest、服務或 live inference；本頁是後續實作的交接。

## 任務與產物

輸入：本機 server 規格、可讀文件與明確 client 版本。

輸出：能力與版本矩陣、讀取結果及拒絕證據。

先完成 [C09-Q06](../exercises/README.md#c09-q06)；替代設計只要滿足相同責任與驗收，可在另行安排實作時比較。

## 環境隔離契約

- 本章是獨立工作單位，資料、依賴 manifest 與 lockfile、測試和啟停說明均留在本章 lab 內；不依賴前章產物、root workspace 套件或其他章的虛擬環境。
- 未來可變檔案、索引、checkpoint 與本機 DB 放本章 lab/.local/，以 C09 作資源命名範圍；任何 server 使用可配置連接埠並在結束時清理自己建立的資源。
- 目錄只是依賴與組織隔離。實際實作還需設定檔案、程序與網路邊界；不得以換目錄宣稱已安全隔離。
- 原生 Codex 登入由既有憑證管理維護；自己的 OAuth app 使用 app 專屬受保護存放位置，不在章內複製登入資料。訂閱額度可能共享，不能宣稱每章有獨立配額。
- 推論以已授權訂閱路線為前提；資格或額度不符時保存狀態並停止，不自動切換計費或要求另一章提供憑證。

## 最低驗收案例

- 必要能力缺失有明確狀態
- 越權讀取被拒絕
- 規格與實作支援分開記錄

所有測試資料明確標為教學資料；真實執行後才增加命令、事件與產物證據。目前不得標記為已跑通。

## 失敗與回退

保留失敗、取消、未知及部分完成，只有產物與狀態符合驗收才算通過。重試先分類、有限次數；副作用未知先讀回。高風險資料變更另需目前狀態、備份、回退、精確 target、必要 transaction 與 timeout。

## 後續實作順序

先把輸入與驗收做成可讀契約，再建立本章獨立環境；先驗證工具與狀態，最後接模型。每次只改一個主要變因。實作語言在該 lab 啟動時依目標選擇，本期教學與題目不依賴特定語言。
