# C09 · 題目

每次先選一題。14 天路線做 Q01、Q03、Q05；7 天先做 Q01、Q05。每題先完成「先交」，有餘力再做「加深」。個人答案放 .study/；卡住才開提示。敘事修訂 2026-10-21，原題 ID 保留。

共同條件：T-1042 r3，2026-10-08 到 10-20 差 12 天；D14 要求≤14 天且未拆封，包裝未知。任務只讀與草稿，沒有寄送、關單或退款授權。

<a id="c09-q01"></a>

## C09-Q01 · 概念重建

以 Codex 讀 D14 為例，畫出 host、client、server。假服務另提供 read_policy、D14 文件、退貨判斷模板，將三者對應 tool、resource、prompt。

**先交：**畫要求經過哪三個角色，標誰查案件權限、誰驗收草稿。

**再補：**把 read_policy、D14 文件、判斷模板分類。

**加深：**同一份 D14 能否改用另一種能力提供？說一個理由。

## C09-Q02 · 方案比較

三個需求是「本 repo 先讓學習者自答」「先查有效版本再算日期與拆封」「讀 T-1042」。團隊想把三者全寫進 Skill，並以 allowed-tools 宣稱可讀任何工單。

**先交：**替三個需求各選位置，說一個理由。

**再補：**指出 Skill 缺工具或權限時，哪一步做不了。

**加深：**只有一個應用、兩個讀取函式，還需要 MCP 嗎？

## C09-Q03 · 軌跡診斷

合成事件：①工具列舉有 read_ticket；②以呼叫者客服 A 讀 T-1042，回 permission_denied；③Skill 寫「必須讀到」；④助理改查其他工單，輸出「T-1042 未拆封」。

**先交：**在四個事件旁寫「這能證明什麼」，圈出第一個不成立的推論。

**再補：**各用一句話寫下一步與對外說法。

**加深：**何時應停止？明確無權限能當暫時故障一直重試嗎？

## C09-Q04 · 架構設計

300 個工具分工單、店規、帳務、行銷。初次探索 8 個候選，再選 2 個詳細契約；另有同名 read_policy 指向測試店，目錄可能缺漏。

**先交：**畫領域索引→詳細契約；加上找不到必要工具時的分支。

**再補：**列執行前四項檢查；挑正選、漏選、舊契約、撤權其中一案走一次。

**加深：**補其餘三個測例，再比較只有 6 個工具時是否沿用。

## C09-Q05 · 面試口答

用兩分鐘向會寫普通函式但沒用過 MCP 的工程師，說明 MCP、Skill、AGENTS.md 的差別，並用 T-1042 示範搭配。

**先交：**按「問題→配置→一次呼叫」說一分鐘，使用 T-1042。

**再補：**加一個拒絕分支及驗收，延長成兩分鐘；合成例子不能說成自己部署成果。

**加深：**30 秒回答「列得出工具，為什麼還讀不到？」。

## C09-Q06 · 未來 Lab 規格

只設計獨立本機 MCP 練習，包含列舉成功、讀取成功、無權限、版本不合、必要工具缺少及 server 不可用六情況。

**先交：**先替「列舉成功」「無權限」寫假輸入、預期觀察、下一步及不能宣稱的結果。

**再補：**沿用格式補齊其餘四情況，標只讀邊界。

**加深：**定義相容表。只交規格，不建程式、依賴或環境，不依賴 hosted MCP。
