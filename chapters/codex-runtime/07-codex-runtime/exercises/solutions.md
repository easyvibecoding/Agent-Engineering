## C07-Q01

客戶端送任務與顯示事件；Codex harness 管工具與模型循環；模型提出結果；環境放文件與命令。Thread 容納互動，turn 是一次請求及工作，item 是其中訊息與工具單位，不等於環境本身。

**核對重點：**入口、執行與資料位置清楚；事件能對回輪次。 若採不同前提，先明確寫出；不能把題目中的未知直接補成已知。

## C07-Q02

報告可從 exec／薄 SDK 起步；工作台可選 app-server。後者需管理連線、事件輪次、失敗與核准回覆，還要核對版本。不是用了 SDK 就自動有完整產品介面。

**核對重點：**兩個情境各有理由；深度整合要承擔事件與版本。 若採不同前提，先明確寫出；不能把題目中的未知直接補成已知。
