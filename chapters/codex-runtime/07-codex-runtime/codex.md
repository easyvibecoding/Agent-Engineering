# C07 · Codex 協作卡

先選一張卡，把自己的答案附上即可，不必四張一起用。請 Codex 等你自答後，每次只追問一步。預設只讀本章正文、設計取捨與題目；你要求提示或解答時，才讀對應檔案。不建立 lab、不改全域設定、不讀登入憑證。

## 卡 1：先選需求，再選入口

「先讓我用一句話說明 T-1042 工作台綠勾代表什麼；我回答後，再讓我選報告入口並說理由。等我回答後，先問是否需要自訂 UI，再問是否要接核准／歷史，最後問增加哪項維護責任。若我只背 CLI、SDK 名字，要我用一次具體操作說明；每次只追問一題，不先給完整比較表。」

## 卡 2：讓我一步步讀事件

「我先回答 Q03。依序問我：讀取 item 證明什麼？片段能交付嗎？turn/completed 中要看哪個欄位？目前工單缺什麼？不要一次全部問完。核對我是否混用 exec 點號與 app-server 斜線 schema。只有我要求提示才看 hints.md；要求解答才看 solutions.md。」

## 卡 3：權限審閱

「這是我 Q04 的第一版，可能還沒填完。先讓我只解釋 cwd；等我回答，再比較 sandbox 或 approval。最後挑一項我宣稱的隔離，問需要哪個觀察才可證明。若我說 read-only 就只讀兩檔，要求我補讀取範圍；不替我建立任何環境。」

## 卡 4：面試與規格

「先以 Q05 讓我口答 90 秒；追問一個 SDK 沒有接走的責任，再問一個 failed／斷線案例。評語用具體證據，不把流暢當正確。等我明確說要切到 Q06，再審閱規格；一次只找一項未定義的輸入、終止或副作用驗收，不執行它。」

教練模型是否能完成這些追問，要看回答是否符合資料與權限；模型可選、登入成功或列出名稱，均不等於本章 lab 已跑通。

被打斷時可貼：「剛才我已說清＿＿，還卡在＿＿。先讓我續答，不重新講完整章。」
