# 07 · Codex Runtime 與訂閱入口

章節 ID：C07 · 內容修訂：2026-10-21 · 約 2–3 小時 · Lab 僅規格，尚未實作。

## 這章要解決什麼

**用 Codex 做同一件事時，哪些工作已由它負責，哪些仍要你檢查？**

上一章分清當輪資料與保存進度。現在用 Codex 的實際介面名詞，對照這些責任。

本章交付：客戶端能指出是哪一輪、哪個工具與哪份產物；介面分開顯示本輪結果與工單業務狀態。

## 跳章入口

你要讓 Codex 讀教學工單 T-1042 與 D14，交條件式草稿。也想知道：直接用 CLI、從程式驅動，或做一個帶核准畫面的客戶端，各該從哪個入口開始。

這是虛構教材案例，不是法律建議、真實客服紀錄或執行證據。完整設定見[共同案例](../../../maps/course-story.md)。 不要求先完成前章練習或啟動任何環境。若名詞陌生，可先讀正文的白話對照，再回查[詞彙表](../../../maps/glossary.md)。
