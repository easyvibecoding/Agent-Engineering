# 07 · Codex Runtime 與訂閱入口

工作台亮了綠勾，客服卻問：「到底做完什麼？」從這個問題開始，不必先背 CLI、SDK 或協定欄位。

章節 ID：C07 · 編修：2026-10-21 · 核心約 2–3 小時 · Lab 只有規格。

## 本章要留下什麼

先讀[正文的四個場景](lesson.md#4-完整走一次從請求到可驗收草稿)。看到「到這裡可以先停」時，你應能說清楚：讀取成功、這輪結束、草稿可用、工單處理完成，分別需要什麼證據。

先別展開深挖表格。你可以只用一句話記下這個綠勾代表什麼，再繼續往下。

## 核心讀法：2–3 小時

1. 跟著正文查綠勾，讀到入口選擇；約 40 分鐘。
2. 做[Q01](exercises/README.md#c07-q01)的核心交付，休息後再做 Q03、Q05；約 45 分鐘。7 天路線先做 Q01、Q05。
3. 選[設計取捨](design-notes.md)裡一個你可能做的決定，說明何時會吃虧；約 20 分鐘。
4. 需要時只開對應[提示](exercises/hints.md)，修正後才看[解答](exercises/solutions.md)；約 20 分鐘。
5. 用[面試](interview.md)或[Codex 卡](codex.md)追問一次，約 15 分鐘。

被打斷時，不用重頭讀。正文末有「下次從這裡接」，填目前判斷、未解疑問、下一個段落或 QID。

## 具體前置與跳章背景

T-1042 r3 的日期差是 12 天，D14 要求不超過 14 天且未拆封；包裝狀態未知，只准讀取與草稿。[共同案例](../../../maps/course-story.md)可補背景，但跳章不需啟動前章環境。

只需要先知道：模型提出工具要求，不等於動作已執行；保存的資料，也不一定仍是現況。不熟時回查[工具契約](../../agent-core/03-tool-contracts/README.md)或[狀態](../../knowledge/06-memory-and-state/README.md)，讀完相關段落就回來，不必重做全章。

## 深挖讀法：另排 45–75 分鐘

準備接工作台時，再讀正文的名詞、事件表和權限。優先查你卡住的問題：事件拼法找 exec／app-server 分界；綠勾錯誤找驗收分支；隔離不清找 cwd／sandbox／approval。

Q02、Q04、Q06 的加深部分可以另排，不拖住核心進度。[未來 Lab 契約](lab/README.md)只寫觀察與驗收，不建立程式、登入或安裝環境。
