# C08 · 未來 Lab 規格

狀態：**僅規格，尚未建立程式、安裝環境或執行。**

## 要練的工作

只寫訂閱 harness 練習的驗收表，至少涵蓋拒絕同意、缺 scope、更新 token、串流斷線、工具拒絕、額度中止和正常完成。

## 獨立輸入

你要做本機客服助理，自己決定讀工單、讀店規、何時停。它想經使用者同意使用 ChatGPT 方案額度；這不是把既有 Codex 登入檔搬進程式。

未來 lab 自帶上述假資料、來源版本與預期條件，不依賴前章留下的資料庫、程序或 token。變體與原案例分開標示。

## 預期產物與驗收

自己的 harness 留下授權狀態、每次推論終止狀態、工具要求與實際結果，最後交付有條件與引用的草稿。

七類各有預期狀態；不啟動 OAuth 或請求。

驗收需保留實際輸入、事件與結果；目前只有規格，不能填寫已通過。資料夾分開不代表有 sandbox，要另驗證程序、檔案與網路邊界。

## 環境與權限契約

實作獲安排後，依本 lab 選擇的語言記錄獨立依賴、啟動與清除方式。可變狀態放本目錄 .local/，不用其他 lab 的狀態；個人答案放 repo 的 .study/。不把真實憑證放進 repo。

基礎案例只讀與草稿；若本題明示另行核准的寫入變體，仍需精確目標、版本與授權，不能推論其他題也有寫入權。推論優先採訂閱路線，資格、工具能力與共用配額需另確認，目錄隔離不會隔離帳號配額。
