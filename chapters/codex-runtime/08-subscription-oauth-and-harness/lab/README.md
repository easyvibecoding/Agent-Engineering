# C08 · 未來 Lab 規格

狀態：**僅規格，尚未建立程式、安裝環境、啟動 OAuth 或執行推論。** 本期交付是假事件與驗收契約。

## 獨立輸入

本 lab 未來自帶 T-1042 r3、D14、D07 的假資料與事件，不依賴其他章的程序、資料庫或 token。10/08 至 10/20 差 12 天；D14 要求 ≤14 天且未拆封；r3 拆封未知。工具只允許本題目標的讀取，任務只交草稿。

事件資料需能表示：授權狀態摘要、request／response ID、推論終止狀態、工具名稱／參數／call_id、工具拒絕或結果、來源版本與最終交付狀態。憑證值不屬於一般 trace。

## 預期產物

- 一張層級狀態表：身分、方案推論授權、本次推論、本機工具、草稿交付。
- 三次推論與兩次讀取的事件表，工具結果能各對回 call_ticket_01、call_policy_02。
- 下列驗收矩陣，執行欄一律先填「未執行」。規格合理不等於測試通過。

## 驗收矩陣

| 合成輸入 | 預期狀態與可否繼續 | 要保留的證據 | 恢復條件 |
| --- | --- | --- | --- |
| 使用者拒絕同意 | 該次授權停止；不交換 code、不推論 | state 驗證結果與拒絕狀態 | 使用者之後主動重新授權 |
| ID token 有效，缺方案 scope | 身分已驗證、方案推論停用 | 實際 granted scopes 摘要 | 新授權確實授予所需 scope |
| 直接 Responses token 更新成功 | 後續請求使用新憑證 | 更新成功與帳號/client 對應，不記值 | 憑證完整替換且請求狀態正確 |
| app-server env_key token 更新 | 舊程序不視為已更新 | 重啟、initialize、thread/resume 的設計事件 | 新程序使用更新憑證且恢復正確 thread |
| 文字片段後斷線，無終止事件 | 推論未確認完成；不交最終答案，不執行該輪候選 | request ID、未完成片段、已完成工具清單 | 依錯誤與保留進度有界接續 |
| read_ticket 被拒絕 | 該工具為拒絕，不以模型猜測代替 | call_id、目標、拒絕原因 | 合法替代或要求補資料；必要時停止 |
| response.failed＋usage_limit_exceeded | 停新方案推論；不改計費，不猜重設 | 精確碼、HTTP 狀態、已知資料 | 官方用量狀態及後續合法請求支持恢復 |
| 正常三輪推論與兩工具 | 交條件式草稿；業務資格待拆封資料 | 三次終止事件、兩配對、r3／D14、草稿 | 本輪完成，停止重複讀 r3 |
| 工單結果誤填政策 call_id | 配對驗收失敗，不進下一輪正常路徑 | 原要求、錯結果與攔截原因 | 修正為原 call_id 且核對名稱與目標 |

## 成功與拒絕契約

成功產物須含 12≤14、未拆封未知、T-1042 r3／D14 來源及未寄送／關單／退款。任何一項缺漏，不能標整體通過。推論 completed 但工具被拒絕，是不同層級的不同結果。

未來真實整合時，再加帳號資格、scope、所選模型、支援參數與工具能力檢查。這些目前未跑；本章不讓假事件取代資格證據。

## 環境與清除契約

只有後續明確安排實作才選語言、建立獨立依賴、啟動／清除指令。可變狀態放本 lab 的 .local/；個人答案放 repo 的 .study/；不共用別章 runtime 或憑證。合法取得的真實憑證須放 app 自己受保護且不進 Git 的儲存位置，不能讀原生 Codex 登入檔取代本 app 授權。

資料夾隔離不代表 sandbox，也不隔離帳號共用額度。真正環境邊界與可用配額需另驗，不能由本契約宣稱完成。
