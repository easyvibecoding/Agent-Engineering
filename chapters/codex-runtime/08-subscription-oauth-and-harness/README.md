## 這章要解決什麼

**如果想自己安排每一步，訂閱 OAuth、Responses 和自己寫的 harness 要怎麼接？**

上一章由 Codex 提供現成循環。這章比較自己掌控循環的方式；兩條路都能拿同一份客服資料作設計。

本章交付：自己的 harness 留下授權狀態、每次推論終止狀態、工具要求與實際結果，最後交付有條件與引用的草稿。

## 跳章入口

你要做本機客服助理，自己決定讀工單、讀店規、何時停。它想經使用者同意使用 ChatGPT 方案額度；這不是把既有 Codex 登入檔搬進程式。

這是虛構教材案例，不是法律建議、真實客服紀錄或執行證據。完整設定見[共同案例](../../../maps/course-story.md)。 不要求先完成前章練習或啟動任何環境。若名詞陌生，可先讀正文的白話對照，再回查[詞彙表](../../../maps/glossary.md)。
