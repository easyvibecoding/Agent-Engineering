# C08 · 面試與追問

## 主問題

用白話回答：用訂閱自己做 harness，和直接用 Codex，是不是同一件事？

先口答兩分鐘：用一句話定義問題，再引用本章資料說明決策、失敗與驗收。不要逐字背參考解答。

## 面試官可以怎麼追

- 方案選擇：如果目標是學習每輪決策，和如果目標是快速做客服操作台，你會如何選自建 loop 或 Codex app-server？
- 出錯定位：教學串流：HTTP 200 → 片段『可以…』→ response.failed，碼為 subscription_sharing_usage_limit_exceeded。現在可交最終答案嗎？如何保留進度？
- 設計落地：畫一次『模型要求讀工單』的往返，標出推論完成、工具真正執行、結果進入下一輪三個時點。

## 自評

每項 0–2 分：是否答到需求；是否引用具體資料；是否說明取捨與限制；是否提出可觀察驗收。0 為缺少，1 為只有概念，2 為能用案例說明。分數只供練習，不代表已通過真實面試。

本題重點：說明推論入口、授權與 loop 負責者。

先自評，再按需看[Q05 參考解答](exercises/solutions.md#c08-q05)。涉及執行成果時，分開說已設計、已實作、已測試；本 repo 的 lab 尚未實作。
