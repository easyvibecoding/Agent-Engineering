# C08 · Codex 協作卡

你可以停在正文任意一步，把當時那個畫面交給 Codex。一次只選一張卡，先讓你回答，下一題等修正後再問。預設只讀正文、設計取捨與題目；未要求提示或解答時，不讀 hints.md／solutions.md。不建 lab、不讀真實憑證、不改全域設定。

## 卡 1：逐關授權教練

「我在學 C08。先只問我：ID token 有效、但缺方案 scope 時，介面應顯示什麼？等我自答並修正後，先問我是否要進深挖。若要，再單獨追問 state；下一回合才輪到 nonce 或 PKCE。不要一次列出所有授權欄位。若我只說『驗證安全』，請我說明要比對哪份資料；不要直接給全套答案。」

## 卡 2：事件桌上推演

「請依正文合成案例當事件主持人。一次給我一個事件：工具要求、completed、本機讀取結果、下一輪。每次先等我選『可執行工具／只能等待／可以交付』其中一個並說理由，再公布下一事件。在其中一輪改成 failed，問我哪個動作要停。不要啟動請求，也不要假裝事件是真實 log。」

## 卡 3：call_id 配對審閱

「我會貼 Q04 的表。先只讓我把 call_id 接到結果；配對修正後，下一回合再問必要 input；最後才檢查 unknown。若有錯，只指出第一個錯配並問我如何修，不立刻重寫完整答案。」

## 卡 4：恢復面試官

「先問 Q03 的核心，等我自答，只追問我第一個推理缺口。若這輪完成，下一輪才從已知工具結果、錯誤資訊、恢復程序挑一件繼續。請把我混用的『成功』換成具體層級，要求我修正後再評分。」

## 卡 5：未來規格審閱

「我只交 Q06 的未來驗收表。依授權、推論、工具、交付順序，逐列找無法客觀驗收的句子，例如『正常恢復』。請問我要看到哪個事件、配對、來源與狀態才算正常；所有執行欄維持未執行。不要建 app、環境或讀憑證。」

## 收尾：讀者保留自己的修正

每次對話留三行：我停在___事件；目前判斷___；下次先回答___。若有修正，再記原判斷與缺少的證據。可用目前可選的訂閱模型作教練，但回答流暢或模型列在選單，不代表練習已驗收；先依題目資料檢查推理。
