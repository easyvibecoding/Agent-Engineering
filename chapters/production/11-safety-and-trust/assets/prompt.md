## 最終提示詞

Use case: scientific-educational. Create a landscape educational conceptual illustration in a refined isometric engineering-workbench style, warm off-white background, soft wood and paper texture, consistent colors: violet model, cyan tools, amber records, coral authority, green checks. Topic: untrusted retrieved content is data, not authority, and tool execution needs an independent permission gate. Left area: a pile of externally sourced paper cards labeled '外部資料'; one card visibly has a small coral warning symbol but NO actual malicious instruction text. Center: a violet processing module labeled '模型' receives selected cards in a clearly delineated reading area. A proposed action card sits between this module and a separate coral gate labeled '權限檢查'. Right: a cyan tool workstation labeled '工具執行' is located inside a clearly outlined, bounded workspace. A clean user authorization card labeled '使用者授權' reaches the permission gate by a physically separate route that does not pass through the external paper pile. On the edge of the bounded workspace a logbook labeled '稽核' records actions. Make the independent authority boundary easy to see and keep the tools inaccessible directly from the external-paper pile. ONLY the six labels above, exact Traditional Chinese, no dense flow arrows, no paragraphs, no URLs, no brand or watermark, no padlock implying perfect security, no robot. The illustration should invite a student to explain why a retrieved document cannot grant itself permissions. Conceptual teaching metaphor, visually clear, not a claim of complete security enforcement.
