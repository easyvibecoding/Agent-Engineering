# C12 · 分級提示

先保留自己的答案。每次只看一級，關起提示再寫一句；不用一次把六題提示讀完。

<a id="c12-q01"></a>

## C12-Q01

1. 把「封包沒回來」和「關單沒發生」寫成不同句子。
2. 分別想像遠端尚未受理，以及已完成但確認遺失；當下訊息只能用目前證據。

[回題目](README.md#c12-q01)

<a id="c12-q02"></a>

## C12-Q02

1. 先想：哪個名稱應能讓遠端認出「還是原來那次關單」？
2. 假設遠端已忘掉這個名稱，它還能替你防重嗎？

[回題目](README.md#c12-q02)

<a id="c12-q03"></a>

## C12-Q03

1. t2 是題目給讀者的真相，重啟程式還不知道；不要跳過查詢。
2. 先只檢查「改用新 ID」這一步：遠端會把它認成同一件事嗎？

[回題目](README.md#c12-q03)

<a id="c12-q04"></a>

## C12-Q04

1. 把「找不到」和「明確無效果」分列，想想查詢來源是否權威。
2. 沿著一條循環走四次；找出哪個數字會阻止它繼續。查詢和重送要分開數。

[回題目](README.md#c12-q04)

<a id="c12-q05"></a>

## C12-Q05

1. 先用一句人話說明「我怕的是第一次其實已成功」。
2. 版本、操作 ID、停止在途工作、另做修正，各處理不同問題。

[回題目](README.md#c12-q05)

<a id="c12-q06"></a>

## C12-Q06

1. 測試知道故障注入在哪，恢復程式不一定知道。
2. 效果次數要觀察工單及附帶事件；一個成功畫面不足以驗收去重。

[回題目](README.md#c12-q06)
