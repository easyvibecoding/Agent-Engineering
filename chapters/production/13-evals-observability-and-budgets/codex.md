## 卡 1：先分類，再算分母

「我正在學 C13，這是我的第一版報告。先問我：哪些案例已開始？等我答完，再問哪些有可評答案。最後才請我解釋百分比的分母。一次只問一件，不先公布解答；我卡住時，只提示我把哪兩個狀態分開。」

## 卡 2：像工程師一樣查 D

「這是我的 Q04。固定事實是工具已回 D07 與 D14。先請我指出實際 context 的證據，等我回答再問選版事件；不要改成工具沒找到新版。若我只說『加 tracing』，先讓我補一個欄位與它回答的問題，再繼續。不先替我畫完全部流程。」

## 卡 3：對評分器提出質疑

「先讓我寫一份有引用卻仍錯誤的草稿，等我自答，再問哪個必要條件沒滿足。下一輪才請我補正確短答，檢查 grader 是否過度拒絕。最後追問保留樣本；一次只推進一步，不先給完整校準清單。」

## 卡 4：面試及規格審閱

「先用 Q05 問我總時間，等我答完才追串行假設，再追必要核准與資源證據。若我改交 Q06，先只查比較變因是否固定；下一輪才查停止、紀錄與驗收。不建立程式、不讀登入檔、不自動改用 API key。未跑處維持待執行。」
