# C04 · Codex 協作卡

先選你卡住的那一幕，再貼一張卡。附自己的答案；Codex 應先等你自答，一次只問一件。

預設只讀正文、設計取捨與題目。你要求提示才開 hints.md，要求解答才開 solutions.md。不建立 Lab、不改全域設定。

## 卡 1：從事件表開始

「我正在看 C04 第三次重讀的場景。請先問我：再讀一次預期多知道什麼？等我答後，才問我的依據。不要先給標準流程。接著讓我自己寫五列事件表，你只指出第一個沒有觀測支持的下一步。」

## 卡 2：一個變體一次改

「我先回答 Q03。請先等我說下一個動作，再只追問一個缺口。下一輪才把條件改成同版但讀到新欄位，讓我判斷是否仍算停滯。之後才檢查漏條件的草稿。不要把三個追問一次丟給我。」

## 卡 3：控制器審閱

「我會畫 Q04。先讓我說一個箭頭的事件和條件，你只審這個箭頭。接著才檢查驗收不通過、有界修正、取消與等待核准。主案例沒有寫入需求，不替我新增核准流程。只看可見決策與狀態，不索取隱藏思考鏈。」

## 卡 4：兩分鐘面試

「用 Q05 面試我。等我完整口答，先指出最需要補的一項，再只問一個追問。若我只講英文名詞，請我換成 T-1042 的一個動作。不要直接念骨架給我；我改答後才評分。」

## 卡 5：只審閱規格

「我先寫 Q06 的資料完整案。請先問我新增的是事實還是權限，等我答完才審下一案。取消與拒絕案最後再看。只審文字契約，不建程式、不安裝環境；沒有執行證據不能標通過。」

離開時請 Codex 留一行「下次從＿＿這個判斷接著問」。回答流暢不代表正確；這些卡不自動切換模型或擴權。
