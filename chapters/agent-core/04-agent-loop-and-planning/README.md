## 這章要解決什麼

**助理怎樣根據剛讀到的結果決定下一步，又不會一直重查？**

上一章把工具的要求與結果講清楚。這章把它們接成循環，並為「缺資料」設一個合理的停點。

本章交付：本輪交付：詢問拆封狀態的草稿。業務進度：等待資料。停止原因：目前可讀來源無法回答拆封問題。
