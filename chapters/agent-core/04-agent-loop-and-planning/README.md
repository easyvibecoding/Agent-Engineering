# 04 · Agent Loop、規劃與停止

助理第三次讀同一張工單，結果還是「拆封未知」。你想拿草稿，它卻繼續轉圈。這章從你要不要讓它再查一次開始。

章節 ID：C04 · 內容修訂：2026-10-21 · 核心約 2–3 小時 · Lab 僅規格。

## 這章解決什麼

先打開[正文](lesson.md)。跟著四個場景走到「把結果交給下一輪」即可；狀態圖、完整事件表與模式比較可以先略過。你先練一件事：指出下一個動作可能帶回什麼，而不是讓助理一直工作。

跳章只需知道：T-1042 r3 相隔 12 天；D14 要求 ≤14 天且未拆封，但拆封未知。只准讀取與草稿。[完整案例](../../../maps/course-story.md)可需要時再查。

## 核心讀法：2–3 小時

先給正文約 45 分鐘。兩次短停頓各寫一句自己的判斷，不必先背英文模式。

接著做 [Q01](exercises/README.md#c04-q01)，把故事改成自己的事件表。14 天路線再做 Q03、Q05；7 天路線做 Q01、Q05。答題與修正合計約 60 分鐘。

剩下的時間讀[設計取捨](design-notes.md)前兩項，選一張[Codex 卡](codex.md)或練一次[面試](interview.md)。卡住先回事件，再按需看[第一級提示](exercises/hints.md)；改過答案才開[參考解答](exercises/solutions.md)。

## 深挖讀法：另排時間

如果你已能說明何時停，才去看正文的狀態機、完整事件表與四種模式。Q02 比較方案，Q04 畫轉移，Q06 只寫 [Lab 驗收規格](lab/README.md)。這些不要求一次完成，也不需要程式環境。

若你看不懂 r3、未知欄位或工具結果，回[第 03 章](../03-tool-contracts/README.md)查這三件事即可。若你只是不確定何時再查，回正文場景一；若你把交草稿當核准，回「先把兩個完成拆開」。

離開時在 .study/ 留一句：「下次我要從＿＿接著判斷＿＿。」第 05 章會接著拆解如何找對政策版本。
