# C04 · 分級提示

先自答。第一級找方向，第二級才縮小範圍；不用一次讀完。

<a id="c04-q01"></a>

## C04-Q01

1. 先不要排所有名詞。找出哪個工具結果改變了下一步。
2. 12 天只證明其中一項；問客戶的草稿可交付，但客戶還沒收到詢問。

[回題目](README.md#c04-q01)

<a id="c04-q02"></a>

## C04-Q02

1. 看決策是在分流、排步驟、根據中間觀測改路，還是依缺陷修產物。
2. 機制可以組合，但不代表每件任務都要經過四段。

[回題目](README.md#c04-q02)

<a id="c04-q03"></a>

## C04-Q03

1. 一種問題在工具查詢，另一種在草稿內容。哪一種靠現有資料就能修？
2. 比較同查詢、同缺漏與新增事實；草稿則對照 D14 的兩條件。

[回題目](README.md#c04-q03)

<a id="c04-q04"></a>

## C04-Q04

1. 等待的是事實，還是權限？先分清；本輪完成與業務完成也不同。
2. 取消後要分未派、已派結果已知、已派結果未知，而非一律清空。

[回題目](README.md#c04-q04)

<a id="c04-q05"></a>

## C04-Q05

1. 先用 r3 的重複讀取說明問題，再講控制方式。
2. 模型的繼續建議不是改上限的權限。測試時即使它堅持也應停止派工。

[回題目](README.md#c04-q05)

<a id="c04-q06"></a>

## C04-Q06

1. 完整資料只讓判斷更完整，沒有新增寄送／退款權限。
2. 取消與核准案要描述在途狀態或拒絕事件，不能只寫一句取消／拒絕。
