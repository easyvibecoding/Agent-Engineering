## C04-Q02 · 方案比較

先替四個動作各配一種模式：辨識退貨問題；依序讀兩個已知來源；看到 D07 後改找有效版；補草稿漏掉的拆封條件。

**寫完再往下：**可用 routing、plan-and-execute、ReAct、evaluator-optimizer。再選一種說它可能怎麼失敗；最後判斷固定讀取任務是否需要四種全上。加深時補齊其他三種的失敗例。

**完成檢查：**四個責任對照合理；最簡方案仍保留缺漏與停止。
