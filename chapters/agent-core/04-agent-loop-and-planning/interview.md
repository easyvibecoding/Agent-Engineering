# C04 · 面試與追問

## 主問題

用 T-1042 回答：你如何防止 Agent 無限循環？

先口答兩分鐘：用一句話定義問題，再引用本章資料說明決策、失敗與驗收。不要逐字背參考解答。

## 面試官可以怎麼追

- 方案選擇：將『辨識是否退貨問題』『依順序查資料』『補上漏掉的引用』分別對到 routing、plan-and-execute、evaluator-optimizer，說明為什麼。
- 出錯定位：教學軌跡：連讀三次 T-1042，版本都 r3、拆封都未知；模型要求再讀十次。下一步應做什麼，如何判定停滯？
- 設計落地：畫出執行中、等待資料、等待核准、取消與完成的轉移；說明取消時外部操作可能怎樣。

## 自評

每項 0–2 分：是否答到需求；是否引用具體資料；是否說明取捨與限制；是否提出可觀察驗收。0 為缺少，1 為只有概念，2 為能用案例說明。分數只供練習，不代表已通過真實面試。

本題重點：提到進展判準、硬上限與缺資料時的下一步。
