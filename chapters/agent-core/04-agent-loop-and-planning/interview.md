# C04 · 面試與追問

## 主問題

面試官問：「你如何防止 Agent 無限循環？」先用 T-1042 r3 口答兩分鐘。暫時不要讀骨架，只要說明重讀哪裡沒進展，以及誰能叫停。

以下是合成案例的面試練習，不是真實面試成果。

## 短答骨架

如果剛才說到一半卡住，先補第一句：「工單多次回 r3、拆封未知，模型仍想重讀。」有了具體失敗，才接控制方式：記來源與新增資訊，沒有可補缺漏的動作就停止重查。

下一句說責任：模型提議，控制器守權限、次數、修正和期限；模型不能替自己加第十一輪。

最後才收在交付與證據：可交詢問草稿，驗收通過後本輪完成，但業務等待客戶。未來用持續相同回傳、模型仍提議繼續的故障案，驗證控制器確實不派新工作。

## 由淺到深追問

一次只抽一問，答完才換下一問：

1. 限制十輪為何不夠？先說前九輪是否可能都沒價值。
2. 同版本就一律停嗎？想一個同版卻帶回新欄位的情況。
3. 評估器說再寫一次呢？先請它指出具體缺陷。
4. 模型說必須第十一輪呢？指出誰有改上限的權限。
5. 取消是否等於還原？把新派工與已派結果拆開。
6. 固定讀兩份文件需要 ReAct 嗎？說明最簡可驗收方案。

## 常見弱答如何改善

若只說「加 timeout」，先補什麼算進展。若只說「自我反省」，改成一個能檢查的缺陷，例如漏 D14 的拆封條件。若說「工具成功就完成」，改說工具讀取、本輪草稿、業務進度三者各證明什麼。

## 自評：四項各 0–2 分

四項分開看：具體失敗、控制責任、停止後交付、故障驗收。0 是缺少，1 是名詞，2 是能用本例說明。先挑最低的一項重答，不必整段重背。
