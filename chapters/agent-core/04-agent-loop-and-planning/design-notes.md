# 04 · 疑難與設計理由

[正文](lesson.md) · [題目](exercises/README.md)

## 需要說得出理由的選擇

### 1. 固定計畫還是動態規劃？

設計理由：固定計畫便於預估與檢查，適合已知流程。

替代方案與改選條件：不確定資訊多時允許重規劃，但保留目標、依據與資源限制。

### 2. 增加反思輪數還是改善評估？

設計理由：沒有外部訊號時，更多反思可能放大既有錯誤。

替代方案與改選條件：先改善失敗判準與觀測，再以相同任務衡量迭代是否有收益。

## 常見疑難

### 疑難 1：停止就等於完成

分開記錄控制循環結束與任務驗收通過。

### 疑難 2：思考寫得長代表有進展

檢查新增證據、狀態變化或驗收項目，而不是文字長度。

## 如何證明選擇有用

以本章案例固定資料與成功條件，只改一項設計；記錄結果、失敗與必要資源。替代方案不是一律較差：回答何時改選，以及你會觀察什麼。尚未執行的驗證清楚標為待驗證。
