# 03 · 工具契約與 Agent-Friendly 介面

章節 ID：C03 · 內容修訂：2026-10-21 · 約 2–3 小時 · Lab 僅規格，尚未實作。

## 這章要解決什麼

**工具要怎樣說明輸入與結果，助理才不會讀錯、改錯或以為資料已完整？**

上一章決定資料袋內容。這章讓模型透過明確工具取得資料，避免用一個模糊的 execute 指令包辦所有事。

本章交付：讀取結果能對回 T-1042 與 r3，清楚寫出拆封未知；任何關單候選要求都因本輪只有讀取授權而被拒絕。

## 跳章入口

T-1042 仍只准讀取與交草稿。現有工具叫 execute，action 可以填『找工單』『關閉』『退款』；結果只有 success=true，看不出實際讀了誰或是否還有下一頁。

這是虛構教材案例，不是法律建議、真實客服紀錄或執行證據。完整設定見[共同案例](../../../maps/course-story.md)。 不要求先完成前章練習或啟動任何環境。若名詞陌生，可先讀正文的白話對照，再回查[詞彙表](../../../maps/glossary.md)。
