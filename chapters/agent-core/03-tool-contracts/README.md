# 03 · 工具契約與 Agent-Friendly 介面

畫面回 success=true，你卻不知道它讀了誰。本章從這個時刻開始，把「成功」拆成能查證的資料。

先開[正文](lesson.md)，跟著一次讀工單走到「核心斷點」。暫時略過完整欄位表，不需要先會寫 JSON，也不用啟動環境。

章節 ID：C03 · 編修：2026-10-21 · 約 2–3 小時。例子為合成；Lab 只有規格。

## 這章要解決什麼

你會先學會確認工具回的是哪張工單，再判斷 unknown 代表什麼，最後決定這次最多能交付到哪裡。英文術語會在需要時才出現。

## 跳章入口

只需記住：T-1042 r3；2026-10-08 到 10-20 差 12 天。D14 要求 ≤14 天且未拆封，但工單未記拆封。任務只准判斷及草稿，不寄送、關單、退款。完整設定見[共同案例](../../../maps/course-story.md)。

前置是分得清「模型提出要求，程式才實際執行」。若這點還模糊，可先回[上一章](../../foundations/02-llm-and-context/README.md)，不必完成前章 Lab。

## 閱讀與練習

讀完核心，先做 [Q01](exercises/README.md#c03-q01)，只寫輸入與結果的第一版。卡在未知值，就回正文的第三步；卡在授權，就回第一步。修正後再口答 [Q05](exercises/README.md#c03-q05)。

14 天路線再做 [Q03](exercises/README.md#c03-q03)，這時才讀正文分頁段落。7 天路線必做 Q01、Q05。需要時才開[提示](exercises/hints.md)，再不確定才看[解答](exercises/solutions.md)。

## 核心與深挖怎麼安排

可分兩次讀，不用一口氣完成：

- 第一段約 60 分鐘：讀核心、寫 Q01、口答 Q05，留下卡住的欄位。
- 第二段約 60–90 分鐘：看分頁與錯誤分流，做 Q03，再選一個[設計取捨](design-notes.md)修正答案。

完整欄位表、Q02／Q04、外部來源和 [Q06 規格](lab/README.md)都能另排。想用對話接讀，可用 [Codex 卡](codex.md)；想練短答，再開[面試卡](interview.md)。

## 如何知道自己懂了

把 success=true 換成一句能查證的話：我讀到 ______ 的 ______ 版本；已知 ______；仍缺 ______；因此這輪只能 ______。

下次從這裡接：目前卡在 ______；下一段／題號是 ______。工具已能清楚回話，接著由[下一章](../04-agent-loop-and-planning/README.md)安排何時繼續、何時停止。
