# 03 · 疑難與設計理由

[正文](lesson.md) · [題目](exercises/README.md)

## 需要說得出理由的選擇

### 1. 粗粒度還是細粒度工具？

設計理由：過度粗粒度會混合權限與錯誤，模型難以選擇。

替代方案與改選條件：過度細粒度增加往返；以使用者可理解且可驗收的工作單位作邊界。

### 2. 傳原始資料還是摘要？

設計理由：小結果保留足夠原文便於驗證。

替代方案與改選條件：大結果先摘要並提供回讀位置與完整性標記，不宣稱摘要涵蓋全部條件。

## 常見疑難

### 疑難 1：schema 通過即執行

仍需驗證權限、資源與業務前置條件。

### 疑難 2：重試會自然修好所有錯誤

先分類可恢復、不可恢復與未知結果，重試需上限。

## 如何證明選擇有用

以本章案例固定資料與成功條件，只改一項設計；記錄結果、失敗與必要資源。替代方案不是一律較差：回答何時改選，以及你會觀察什麼。尚未執行的驗證清楚標為待驗證。
