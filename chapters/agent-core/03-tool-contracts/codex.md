# C03 · Codex 協作卡

先附自己的答案。預設只讀 lesson、design-notes 與 exercises/README；提示或解答要在你明確要求後才讀。以下是對話建議，不建立工具程式或變更設定。

## 對話一：把契約說完整

貼給 Codex：「我正在學 C03，這是我的 read_ticket 契約。一次只追問一個缺口，先等我答。依序問：模型填什麼？可信環境提供什麼？回傳如何證明讀對 ID 與版本？unknown 怎樣保留？最後指出第一處會讓使用者誤會的語句，不直接替我重寫全文。」

你答完輸入才進結果，不讓一次大量反饋淹沒主題。如果只寫『身分從參數來』，請教練追問：模型能否改那個參數？

## 對話二：用反例測試理解

「先等我解釋 Q03。再依序給我第二頁成功、第二頁失敗、cursor 沒前進三個變體；每次只給一個，要求我寫已知、未知、下一步及可交付說法。不要把不同變體合併；沒有實際工具就稱為紙上推演。」

## 對話三：面試與修正

「用 Q05 問我，先等兩分鐘口答。第一輪只檢查我是否把 Schema、授權、業務正確混成一層；第二輪問拆工具的代價；第三輪讓我給一個可觀察驗收。若我只背術語，要求我用 T-1042 r3 的具體欄位重新說。」

## 對話四：審閱未來 Lab 規格

「這是我的六類驗收表。檢查每列是否有合成輸入、預期工具結果、允許動作、禁止動作與證據。先問我為什麼寫入逾時不能立即重送，再指出規格缺口。不建立程式、不呼叫真系統、不讀憑證、不把規格標為通過。」
