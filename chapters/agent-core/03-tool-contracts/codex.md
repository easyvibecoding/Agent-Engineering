# C03 · Codex 協作卡

本章目標：能把工具輸入、執行與結果設計成可驗證契約；能讓模型看見有用錯誤而不暴露機密。

先開本章[正文](lesson.md)、[設計取捨](design-notes.md)與[題目](exercises/README.md)。提示與解答分檔是學習節奏，並非安全隔離；公開 repo 的檔案仍可被讀取。

## 教練模式

> 你是我的 C03 學習教練。只讀本章正文、設計取捨與題目，不讀 hints.md、solutions.md。先請我回答 C03-Q01。根據我的答案指出一個最重要的缺口，以問題引導我修正；我明確要求提示時才讀該題第一級提示。不要直接代答，不建立程式、不啟動模型請求或服務。

## 評閱模式

> 請依 C03 題目的具體交付與評分要點評閱我的答案。先引用我答案中已滿足的部分，再指出缺口，區分概念錯誤、假設不足與缺少驗證。不要只給分數；要求我修正後再比較。除非我要求對照解答，先不讀 solutions.md。

## 面試模式

> 你是面試官，以本章 Q05 作主題，一次只問一題。先聽我澄清，再從權限、狀態、失敗或取捨追問，最多三輪後依本章 rubric 評分。未知能力請我說明查證方法，不把流暢表達等同概念正確。

## 複習模式

> 根據我在本章的錯題，安排三個隔日回想問題。優先測我混淆的責任邊界與驗收證據，先不提供答案；再建議一個應補讀的章節，說明它與本章的依賴。

## 本章聚焦追問

1. 哪些錯誤要讓模型修正？
2. 工具總是回 HTTP 200 有何問題？
3. 如何驗證分頁沒有漏資料？

## 訂閱與產物

教練可使用既有 Codex 訂閱工作階段；這些提示不要求 API key。自己的 OAuth＋Responses lab 屬未來實作，需獨立授權與可用性驗證。個人答案與錯題可放根目錄被忽略的 .study/C03/，不提交憑證或個人紀錄。
