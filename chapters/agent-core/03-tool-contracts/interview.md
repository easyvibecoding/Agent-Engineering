# C03 · 面試與追問

## 主問題

用讀 T-1042 的例子解釋：什麼叫對 Agent 友善的工具介面？

先口答兩分鐘：用一句話定義問題，再引用本章資料說明決策、失敗與驗收。不要逐字背參考解答。

## 面試官可以怎麼追

- 方案選擇：比較 execute(action) 和 read_ticket／close_ticket／refund 三個工具。哪種比較容易限制本輪只讀？拆工具的代價是什麼？
- 出錯定位：搜尋回 10 筆，另有 has_more=true、next_cursor=page-2。模型卻說『全部只有 10 筆』。該修模型行為、介面，還是兩者？
- 設計落地：把缺 ticket_id、讀取無權限、讀取暫時失敗、關單回覆逾時分成四列，寫各自下一步與停止條件。

## 自評

每項 0–2 分：是否答到需求；是否引用具體資料；是否說明取捨與限制；是否提出可觀察驗收。0 為缺少，1 為只有概念，2 為能用案例說明。分數只供練習，不代表已通過真實面試。

本題重點：定義後舉輸入、結果及錯誤各一例。
