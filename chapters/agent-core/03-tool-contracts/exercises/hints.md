# C03 · 分級提示

先留第一版答案。每題先讀第一級，修正後仍卡住才讀第二級。

<a id="c03-q01"></a>

## C03-Q01

1. 只看到工具結果的人，怎麼知道讀對誰、讀到哪個版本？
2. 身分與權限不能由模型自己宣稱；再檢查資料未填與連線失敗是否被你都寫成空白。

[回題目](README.md#c03-q01)

<a id="c03-q02"></a>

## C03-Q02

1. 先按授權和副作用分類，而非先追求工具數越多越好。
2. 三種操作可具名；80 個讀欄位可按任務合併。無論介面如何，仍要有執行層拒絕。

[回題目](README.md#c03-q02)

<a id="c03-q03"></a>

## C03-Q03

1. 第一頁的筆數是「這批多少」，不是「總共多少」。
2. A 要合併第二頁並核對唯一項目；B 只有部分結果。已有 has_more 時，不要把問題全推給工具沒說清楚。

[回題目](README.md#c03-q03)

<a id="c03-q04"></a>

## C03-Q04

1. 先判斷是否真的執行過，以及結果是否確定。
2. 缺參數與無權限不是暫時服務故障；寫入逾時沒有證明沒寫成。

[回題目](README.md#c03-q04)

<a id="c03-q05"></a>

## C03-Q05

1. 用「何時用、填什麼、能證明什麼、失敗怎麼辦」組織口答。
2. 合法字串不能證明此人可讀該案件；讀取成功也不能證明符合 D14 全部條件。

[回題目](README.md#c03-q05)

<a id="c03-q06"></a>

## C03-Q06

1. 先每類寫一筆假輸入，避免只寫「應安全可靠」。
2. 驗收要同時看輸出與外部狀態；未知寫入的預期是查證或升級，不是立即重送。

[回題目](README.md#c03-q06)
