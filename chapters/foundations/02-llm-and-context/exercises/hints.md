# C02 · 分級提示

先自答。第一級只找方向；第二級再查漏掉的關係。

<a id="c02-q01"></a>

## C02-Q01

1. 先列這次送入模型的東西，再列只存在外面的東西。
2. 把「保存→讀取→選取→放進本輪輸入」畫成一條路；容量則分單位、總範圍與輸出預留。

[回題目](README.md#c02-q01)

<a id="c02-q02"></a>

## C02-Q02

1. 先列「缺了它就會改錯結論」的資訊。五段可合併，不必犧牲第二個條件。
2. D07 與 30 頁紀錄可以有索引；若題目改為比較新舊政策，D07 的地位會改變。

[回題目](README.md#c02-q02)

<a id="c02-q03"></a>

## C02-Q03

1. 把長句拆成可查的主張；12 天正確，不代表其餘正確。
2. 查 D14 生效資訊、D07 的 7 天、r3 拆封欄與原任務。草稿完成不是退貨核准。

[回題目](README.md#c02-q03)

<a id="c02-q04"></a>

## C02-Q04

1. 先寫下一輪必須作的決定，再決定歷史要留什麼。
2. 驗真是拿摘要回比原始資料；不要拿摘要自己證明自己。

[回題目](README.md#c02-q04)

<a id="c02-q05"></a>

## C02-Q05

1. 容量、相關性、版本適用關係是三件事。
2. 不要只比答案長度；先定義錯版、漏條件、把未知當已知三種錯。

[回題目](README.md#c02-q05)

<a id="c02-q06"></a>

## C02-Q06

1. 先做三個已知正確答案的案例，再定三種組裝方式。
2. 讓各組取得來源的權限相同；差別是預載／摘要／補讀，不是誰獨占 D14 原文。
