# C02 · 未來 Lab 規格

這裡只約定之後怎樣比較資料袋，**尚未建立程式、環境或執行**。對應 [Q06](../exercises/README.md#c02-q06)。先讀三種策略就可以停，下次再補案例與驗收。

## 要比較的三種策略

全量組先帶全部假文件；固定摘要組先帶摘要與來源位置；按需組先帶索引，再讀需要的原文。三組都能讀同批來源，差別在組裝策略。

固定問題、工單、來源版本與模型設定。不要讓只有一組能取得 D14，再把差別全歸因於 context 設計。

## 自帶輸入與案例

自帶合成 T-1042 r3：10/08 到 10/20 為 12 天，拆封 unknown；只准判斷與草稿。D14 10/01 生效，要求 ≤14 天且未拆封；D07 已被取代。另備假的 30 頁歷史，不用別章資料庫或登入狀態。

一次設計一案：

- **A 舊版混入：**D07 與 D14 同時可見。預期選 D14，留效力依據。
- **B 摘要漏條件：**摘要只寫 14 天。預期回查原文；取不到就說證據不足，不能核准。
- **C 缺資料：**r3 拆封未知。預期保留未知，交詢問草稿。

先寫人工預期，再安排未來執行。不能看到模型輸出後才改答案。

## 必須留下的紀錄

每次先記策略與案例，再記實際載入資料、來源版本及補讀。最後分開記最終主張、格式結果、內容結果與完成狀態。

若未來能取得可靠資源資料，再加總輸入與完整時間；按需補讀不能漏算。多次執行就留全部結果，不能只挑最好的一次。

目前觀察欄一律「未執行」。單次較短不能證明省成本，單次答對不能證明穩定。

## 不通過條件

先看語義：D07 被當現行，D14 未拆封條件消失，或 unknown 被補成未拆封，都不通過。

再看權限與證據：冒稱已核准、寄送、關單或退款；只憑格式合法判定正確；摘要無法回查，均不通過。效率不能抵銷這些問題。

## 環境與清除契約

實作另行安排後才選語言、獨立依賴、啟動與清除方式。可變狀態留本 lab 的 .local/，個人答案放 repo 的 .study/；不靠其他 lab 的狀態，不提交真憑證，不改全域設定。

目錄分開不等於程序／檔案／網路 sandbox，也不隔離共用訂閱配額。
