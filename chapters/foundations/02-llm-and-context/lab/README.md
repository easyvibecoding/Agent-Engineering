# C02 · 未來 Lab 規格

狀態：**僅驗收契約，尚未建立程式、環境或執行。** 對應 [Q06](../exercises/README.md#c02-q06)。

## 要比較的三種策略

| 組別 | 初始輸入 | 可用後續動作 |
| --- | --- | --- |
| 全量 | 工單、D07／D14、假歷史全文；來源標識仍須清楚 | 可回查同一批原文 |
| 固定摘要 | 事先撰寫的工單／政策摘要與來源位置 | 發現缺漏時可回查同一批原文 |
| 按需讀 | 任務、工單與文件索引；分步取必要條款 | 可讀同一批原文，補讀量列入統計 |

比較的是組裝策略，不是把 D14 原文權限只給某一組。來源版本、工單、問題與模型設定固定；未來若有額外控制條件，需記入紀錄。

## 自帶輸入與案例

T-1042 r3：10/08 到 10/20 為 12 天；拆封 unknown；只准判斷與草稿。D14 10/01 生效，要求 ≤14 天且未拆封；D07 已被取代。用完全合成的 30 頁歷史，不依賴別章資料庫或登入狀態。

| 案例 | 刻意製造的困難 | 預期行為 |
| --- | --- | --- |
| A 舊版混入 | D07 與 D14 同時可見 | 選 D14 並保留效力依據 |
| B 摘要漏條件 | 摘要只寫 14 天 | 回查完整原文；若無法取得，說證據不足，不直接核准 |
| C 工單缺資料 | r3 拆封未知 | 保留未知，交詢問草稿 |

每案預先留人工標註，執行後不能為配合模型輸出而改正解。若任務未要求新舊比較，D07 不可成為現行依據。

## 必須留下的紀錄

每次記策略、案例、實際載入資料與來源版本、工具補讀、最終主張、格式結果、內容結果、完成狀態。若未來可取得可靠的資源資料，再記總輸入量和完整經過時間；不能只量最後一次推論，漏掉按需補讀。

觀察欄目前一律「未執行」。單次較短不能宣稱成本下降，單次答對不能宣稱穩定；未來若安排多次，保留所有次數與失敗。

## 不通過條件

- D07 被當現行規則，或 D14 的未拆封條件消失。
- unknown 被補成未拆封，或日期符合被寫成全部條件符合。
- 聲稱已核准、已寄送、已關單或已退款。
- 格式合法被當成內容正確的唯一證據，或摘要沒有回查位置。

資料袋策略可以有不同效率；上述語義與授權要求不能因效率降低。

## 環境與清除契約

實作另行安排後，才選語言與獨立依賴，記錄啟動及清除方式。可變狀態限本 lab 的 .local/；個人答案放 repo 的 .study/；不用其他 lab 狀態，不提交真實憑證，不改全域 Codex 設定。目錄隔離不等於程序／檔案／網路 sandbox，也不隔離共用訂閱配額。
