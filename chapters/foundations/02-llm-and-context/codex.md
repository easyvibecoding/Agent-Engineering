# C02 · Codex 協作卡

本章不是請 Codex 代寫正解，而是練「選資料→保留未知→驗真」。把自己的第一版答案附上，再選一張卡。預設只讀本章正文、設計取捨與題目；提示／解答要等你明示要求。

## 卡一：五段資料袋教練

「我正在學 C02，先不要給參考資料袋。請依序問我，每次只問一個問題並等我回答：①這輪交什麼、禁止什麼？②哪版規則適用、依據在哪？③日期支持哪個條件？④拆封欄代表已知還是未知？⑤不帶的資料何時再查？若我只說『相關資料』，追問具體欄位與來源。最後指出我漏掉的第一個必要資訊。」

## 卡二：格式與事實分開診斷

「這是我的 Q03 分析。請先讓我把每句拆成可核對的主張，不直接列完錯誤。問我 JSON 是否能合法，再逐項問 D07 的效力、12 與 7 的關係、未拆封的來源、草稿與核准的差別。我的答覆若把內容錯說成格式錯，請解釋兩者用不同檢查；不要替我發明不存在的工單資料。」

## 卡三：壓縮後接手測試

「以下是我的五行交接。請先只憑交接回答：是哪張哪版、採哪版規則、已知與未知、可做與不可做、下一步。找不到就標『交接未提供』，不要猜。接著我貼原始資料，你才逐項對照丟失資訊，給一個最小修正建議。原文的未知不能因摘要省略而變已確認。」

## 卡四：面試與規格審閱

「先問我 Q05，等兩分鐘口答後，依容量與正確性、具體錯例、代價、驗證四項追問。若我要審 Q06，只檢查控制變因、三組來源權限是否相同、三案預期與未執行狀態；不寫程式、不安裝依賴、不讀憑證、不改全域模型設定。不要把設計規格稱已跑通。」

練習結束請自己寫一句修正紀錄：「原本漏了＿＿；現在用＿＿資料核對」。模型的順暢回答不是驗收，仍以題目給定資料為準。
