# C02 · Codex 協作卡

選一張卡，附自己的第一版答案再開始。每次只處理一個缺口；不用一次把所有卡跑完。預設只讀正文、設計取捨與題目，提示和解答等你明示要求才開。

## 卡一：五段資料袋教練

「我正在學 C02。先問我：這輪要交什麼？等我答完，才問允許做什麼。接著依我的答案，逐次追問來源版本、必要條件與未知；一次只問一件，不預先列出正解。如果我只說『相關資料』，請我指出一個具體欄位及用途。」

## 卡二：格式與事實分開診斷

「這是我的 Q03 分析。先讓我選一句主張，再問它由哪筆資料支持。不要一次列完所有錯誤。若我把內容錯說成 JSON 無效，追問格式到底檢查什麼。等我修好這一句，才繼續下一句；不要補造工單資訊。」

## 卡三：壓縮後接手測試

「這是我的五行交接。先只問一個接手問題：還缺什麼資料？若交接沒提供就說沒提供，不要猜。等我貼原文後，再挑一項資訊回比，給最小修正。一次檢查一項，最後才確認能否接手下一輪。」

## 卡四：面試與規格審閱

「先問我 Q05，等我口答後，挑最弱的一點追問，不直接給短答骨架。若我改審 Q06，先問控制變因，再一次問一個驗收條件。不寫程式、不安裝依賴、不讀憑證、不改全域設定，不把規格稱已跑通。」

如果想停，請 Codex 只回三行：我已分清＿＿；還卡在＿＿；下次先問＿＿。這是學習進度，不是模型表現證明。
