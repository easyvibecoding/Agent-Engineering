# C02 · 面試與追問

## 主問題

Context 很大，為什麼仍要挑選資料？用 D07／D14 說明。先自己口答兩分鐘，再用以下骨架檢查；不要逐字背。

## 短答骨架

1. **問題：**容量不會告訴模型哪版有效；舊版、新版與無關紀錄可能一起出現。
2. **具體決策：**T-1042 r3 的兩日期、拆封未知，以及 D14 的兩個條件和生效關係先帶；D07 作歷史索引。
3. **代價：**按需讀增加往返，摘要會漏條件，所以原文與位置不能丟。
4. **驗證：**固定問題、來源、模型設定，比較錯版、漏條件、把未知當已知，以及整體時間與載入量；這是評估設計，尚無實測結果。

## 追問階梯

| 追問 | 面試官在查什麼 | 回答至少要落到哪裡 |
| --- | --- | --- |
| 只有五段資料，你怎麼放？ | 是否分資訊必要性與字數 | 合併 D14 兩條件，保留限制與 unknown |
| 格式已經合法，還驗什麼？ | 是否混淆語法與真實性 | D07 過期、12＞7、未拆封無證據 |
| 摘要會失真，為什麼還用？ | 能否承認取捨 | 留決策條件與原文位置，逐項回比 |
| 每輪都把資料放更多不就好？ | 是否有選擇條件 | 政策比較需要 D07；本輪判斷通常不用全文歷史 |
| 怎樣證明你的策略比較好？ | 是否用觀察取代感覺 | 同條件多次留結果，不只挑一個好答案 |

## 常見弱答如何修

「我會做 context engineering」只報名詞；改成「我會把 D14 生效資訊與未拆封條款一起帶入」。

「把 context 壓短可以省一半成本」跳過了資源口徑；改成「先量實際載入與補讀量，再分開比較時間與配額／費用，不能從字數推定比例」。

「用 JSON 就不會幻覺」把格式當事實；改成「欄位先驗合法，再核對 r3 是否有未拆封證據」。

## 自評與誠實表述

每項 0–2 分：問題有具體錯例、方案有採用條件、取捨有代價、驗收可觀察。0 是未答、1 是抽象、2 是落到本例。分數只供練習，不代表真實面試成果。

若尚未執行，說「我設計比較三種資料袋」，不要說「我已證明準確率提升」。需要才讀 [Q05 參考解答](exercises/solutions.md#c02-q05)。
