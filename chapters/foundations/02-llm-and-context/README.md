# 02 · LLM 與 Context Engineering

章節 ID：C02 · 修訂：2026-10-21 · 核心約 2–3 小時 · Lab 僅規格。

## 這章做什麼

你會把散在文件、工單與歷史對話裡的資訊，整理成模型這一輪真正能用的「資料袋」。不只縮短文字，而是讓每個結論能對回來源、未知與授權。

具體交付是五段 context 與一張驗收表：任務限制、T-1042 r3、兩日期、拆封 unknown、D14 兩條件及回查位置；能指出合法 JSON 為何仍會答錯。

## 前置與跳章入口

只需知道：模型建議下一步，harness 安排執行與限制。若不懂這兩者，先讀[第 01 章](../01-agent-and-harness/README.md)的責任說明，不必完成任何 lab。

本章假工單 T-1042 r3：10/08 到 10/20 相差 12 天；現行 D14 要求 ≤14 天且未拆封，拆封未知。D07 已過期；任務只判斷並寫草稿。完整[共同案例](../../../maps/course-story.md)可回查。

## 核心讀法：先能做對，再讀深

1. [正文](lesson.md)讀到「驗收這一袋資料」：先自己判斷哪些資料必須帶入，約 35 分鐘。
2. 接著讀「格式對與內容對」，做 [Q01、Q03、Q05](exercises/README.md)，約 45 分鐘。
3. 看[取捨一、二](design-notes.md)，修正答案，再用[面試卡](interview.md)口答，約 30 分鐘。
4. 回想五項不能丟的資訊，約 10 分鐘。需要提示時才讀 hints；要求解答時才讀 solutions。

7 天路線必做 Q01／Q05；14 天路線加 Q03。來源閱讀或額外反思另留 20–30 分鐘，不要求首輪讀完論文。

## 深挖讀法

讀正文後段的壓縮對照表，再做 Q02／Q04：把長歷史縮成五行，逐項回比原文。最後用 Q06 設計三種資料袋比較，不執行。這部分約另加 45–60 分鐘，可排後續複習。

[Codex 協作卡](codex.md)會依序追問資料選取、壓縮與驗真，先讓你作答。[未來 Lab](lab/README.md)只定義輸入、輸出與驗收，尚未建立程式或環境。

## 如何知道自己懂了

不看正文也能說出：為何採 D14；12 天只支持哪一條件；unknown 不能變成什麼；哪段筆記還沒進 context；格式成功後還要驗什麼。若只能說「優化 prompt」，回到 worked example 的判斷帳。
