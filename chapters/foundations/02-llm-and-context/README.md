# 02 · LLM 與 Context Engineering

你把整包歷史交給助理，它卻把「拆封未知」答成「可以退貨」。這章先陪你找出漏了哪個判斷，再談 context、壓縮與格式。

章節 ID：C02 · 修訂：2026-10-21 · 核心約 2–3 小時 · Lab 僅規格。

## 這章做什麼

先打開[正文](lesson.md)，跟著四步整理這一輪輸入。先不用背名詞，也不用準備任何環境。讀到第四步，就可以做 [Q01、Q03、Q05](exercises/README.md)。

## 前置與跳章入口

只需知道：模型提出建議，harness 安排執行與限制。若卡在這裡，回[第 01 章](../01-agent-and-harness/README.md)看責任分工即可，不必完成前章 Lab。

案例是虛構工單 T-1042 r3：10/08 到 10/20 相差 12 天；現行 D14 要求 ≤14 天且未拆封，拆封未知。任務只判斷並寫草稿。背景忘了就查[共同案例](../../../maps/course-story.md)。

## 核心讀法：先能做對，再讀深

先留 35 分鐘讀正文四步。碰到微停頓就選一次，不用寫長答案。

接著用約 45 分鐘自答必做題；卡住先回對應段落，需要才開 hints，想核對解法才開 solutions。7 天路線只必做 Q01／Q05；14 天路線再加 Q03。

最後留約 30 分鐘選讀[設計取捨](design-notes.md)，用[面試卡](interview.md)口答一次。剩下時間回想或讀來源，不要求首輪全部讀完。

## 深挖讀法

正文的「深挖」可以先略過。下次回來先看壓縮對照表，再做 Q02／Q04；Q06 只設計三種資料袋的比較，不執行。這部分可另留 45–60 分鐘。

想用 Codex 陪練，貼[協作卡](codex.md)並附第一版答案。它應一次只問一件事，等你答完才追問。[未來 Lab](lab/README.md)則是之後的驗收契約。

## 如何知道自己懂了

把開場那句「可以退貨」改成有證據支持的說法，再解釋你為什麼保留未知。如果還答不出來，回正文第三步；如果只是不確定格式與事實的差別，從第四步接。

離開前記一行：「我停在＿＿；下一次要確認＿＿。」下一章會把補讀需求變成[工具契約](../../agent-core/03-tool-contracts/README.md)。
