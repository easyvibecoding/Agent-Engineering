# C01 · Codex 協作卡

你不必一次請 Codex 教完整章。先貼自己的兩三句答案，讓它只追一個決定；答完，再往下走。

預設只讀本章正文、設計取捨和題目。我要求提示才讀 hints.md，要求解答才讀 solutions.md。這些卡不建立 Lab、不裝依賴、不讀登入資訊、不改全域設定。

## 一次只追一層的對話順序

先貼這張起始卡：

> 我正在學 C01，這是我的答案：＿＿。合成 T-1042 r3 日期差 12 天，D14 要求 ≤14 天且未拆封，包裝未知；只准草稿。請先只問「這輪到底要交什麼」，等我回答後再指出第一個缺口。不要一次貼完整解答。

等你答完，才請它依需要選下一個追問：

- 分工不清：先挑「真的讀工單」，問誰做、拿什麼證明。
- 多做步驟：問資料已附時哪一個動作能省掉。
- 停不下來：問沒有新來源時，再讀 r3 會多出什麼。
- 選型太快：問如果缺欄位只套固定詢問，Agent 多解決了哪件事。

每次回答後，先請它指出你答案中一個成立的依據、再指出第一個不成立的推論。若只剩英文術語，要求你換成一個本例動作。用自己的話改一行，再繼續。

## 卡 2：診斷完成宣稱

> 這是我的 Q03 答案：＿＿。先請我指出一項已證明的事，等我回答再問一項未證明的事。若我把觀察範圍放大，提醒我回到事件；若我想補做，先問誰授權。最後才依題目的分點標準給建議。

## 卡 3：畫圖審閱

> 這是我的 Q04 圖：＿＿。先只走「資料已附」這條路，找一個不必要動作。等我改圖，再走缺資料或越權候選其中一條。最後檢查交付核對失敗是否有修正上限與停止出口，不直接替我完成圖。

## 卡 4：面試與規格

> 先問 Q05，等我 90 秒口答後只追一個弱點。若接著看 Q06 規格，也一次只看一個測試，請我分開預期文字與實際事件。沒有執行的項目留「尚未執行」，不要產生通過紀錄。

中斷前請 Codex 幫你留下：「我已說清＿＿；還卡在＿＿；下次從＿＿開始。」這是學習交接，不是替你編造已懂或已做。

模型可以作教練，答案仍要對回題目資料；一次回答不證明整個 Agent 可靠，也不需要因此自動換模型。
