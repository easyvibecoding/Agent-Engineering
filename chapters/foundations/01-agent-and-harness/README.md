# 01 · Agent 與 Harness 全貌

章節 ID：C01 · 內容修訂：2026-10-21 · 核心約 2–3 小時 · Lab 僅規格，尚未實作。

本章要回答：**模型能提出好建議以後，誰負責真的讀資料、阻止越權，以及確認交付？**

## 前置與跳章入口

只需能讀一張資料表，理解兩個日期相減，並區分「想做」與「真的做了」。不用 API、OAuth、程式環境或前章成果。這是全課起點，不熟英文名詞就先看正文白話表。

合成案例：T-1042 r3，2026-10-08 買入、10/20 申請，差 12 天。D14 要求 ≤14 天且未拆封，r3 包裝未知。只准判斷與草稿，不能寄送、關單、退款。完整設定見[共同案例](../../../maps/course-story.md)。

## 核心讀法：今天交出兩張東西

1. 讀[正文](lesson.md)到「本章驗收」，約 45 分鐘：畫一張誰負責什麼的表。
2. 讀[設計取捨](design-notes.md)前兩項，約 20 分鐘：寫出為何本例不必然需要 Agent。
3. 自答[Q01、Q03、Q05](exercises/README.md)，約 45 分鐘：完成責任表與 90 秒口答。
4. 用[Codex 協作卡](codex.md)追問與修正，約 20 分鐘；需要時才開[提示](exercises/hints.md)或[參考解答](exercises/solutions.md)。
5. 用最後 10 分鐘寫條件式草稿，分開「草稿完成」與「資格待確認」。

7 天路線核心只做 Q01、Q05。不要為了讀完全部延伸而犧牲自答。

## 深挖讀法：第二輪再做

讀正文「延伸：自主程度」、設計取捨第三項，再做 Q02、Q04。用[面試追問](interview.md)驗證你是否能更換條件而不背答案。Q06 與[Lab 契約](lab/README.md)只寫未來驗收，不建立程式或依賴。

## 如何知道自己懂了

能說明固定流程何時夠用；能區分模型候選與工具執行；能用 r3、D14、12 天和包裝未知交出草稿；能指出越權由哪裡攔下，以及什麼證據才可宣稱完成。

接著需要確保模型每輪都看得到正確的事實、限制和來源，前往第 02 章整理 context。
