## 這章要解決什麼

**收到「幫我判斷這張工單」時，模型、工具和你寫的程式各要做什麼？**

這是起點。我們先把「要交什麼」講清楚，後面才知道為什麼需要上下文、工具、記憶與權限。

本章交付：「依 D14，申請相隔 12 天，符合天數條件；工單尚未記載是否拆封，需先確認。以下提供詢問草稿。本次未寄送、關單或退款。」
