# C01 · 題目

從一題開始，不用一口氣做完。14 天核心是 Q01、Q03、Q05；7 天核心先做 Q01、Q05。每題「先做」可先留下第一版，「再加深」用來完成原有知識範圍。

共用合成資料：T-1042 r3，2026-10-08 買入、10/20 申請，差 12 天。D14 要求 ≤14 天且未拆封；包裝未知。只准判斷和草稿，不寄送、不關單、不退款。變體只在明示題目生效。

寫到一半離開，可留「我已判斷＿＿；下一步補＿＿」。先自答，再按需要看一級提示。個人答案放 repo .study/。版本：2026-10-21；沒有 Lab 實測紀錄。

## C01-Q01 · 概念重建

你準備接手這套助理。桌上有四張工作卡：算出 12 天、建議追問拆封、真的讀 T-1042 r3、拒絕關單。

**先做：**先替四張卡各寫一個負責者。再挑一張，寫下怎樣才知道它真的完成。

## C01-Q02 · 方案比較

你要接三項工作：A 把 CSV「姓名」欄改成 name，衝突回報；B 判斷固定日期及包裝欄位，缺欄位一律產生固定詢問；B2 才加入不固定的附件類型及來源選擇。

**先做：**先為 A、B、B2 各選一種做法：固定流程、模型單步或有限 Agent。每個只寫一個原因。

**再加深：**挑一個選擇，補代價與改選訊號。不要只因 B 是中文客服就判定需要 Agent。
