# C01 · 分級提示

先自答。第一級幫你選觀察方向；仍卡住再開第二級，不必一次讀完六題。

<a id="c01-q01"></a>

## C01-Q01

**第一級：**先分「想要讀」和「真的讀到」。再分資料判斷與可執行權限。

**第二級：**表中的證據應是數值、工具回傳或拒絕事件；不是每一格都填「模型說」。runtime 是運作軟體，environment 是可接觸的資源。

[回題目](README.md#c01-q01)

<a id="c01-q02"></a>

## C01-Q02

**第一級：**不要把缺資料與需要自由選路畫等號。B 已把缺欄位的動作寫死了。

**第二級：**B2 才可能需要根據附件內容改變路徑；也可以先用固定分類加人工接手。比較額外彈性是否值得額外錯誤與除錯成本。

[回題目](README.md#c01-q02)

<a id="c01-q03"></a>

## C01-Q03

**第一級：**把每筆紀錄能證明的最小事實寫出來。e4 有文字，並沒有寄送收據。

**第二級：**無法由這條紀錄證明外部任何流程都沒寄信，但能確定本輪沒有寄送證據。更正後不能偷偷補寄，因為 e1 沒授權。

[回題目](README.md#c01-q03)

<a id="c01-q04"></a>

## C01-Q04

**第一級：**不要把讀取畫成所有輸入必經。先問資料是不是已提供。

**第二級：**缺資料且沒有新來源時，可交條件式草稿並停止；有獲准的新來源才回到讀取。權限不能靠模型自我核准。

[回題目](README.md#c01-q04)

<a id="c01-q05"></a>

## C01-Q05

**第一級：**先講這次要交草稿，再用一句話定義 harness，最後補實際動作。

**第二級：**把「更準確」拆成哪個錯：日期、資料版本、權限或完成宣稱。再給一個 workflow 已足夠的輸入條件。

[回題目](README.md#c01-q05)

<a id="c01-q06"></a>

## C01-Q06

**第一級：**每個測試都分「內容怎麼答」和「事件可以出現什麼」。

**第二級：**完整條件變體仍只准草稿；資料完整不會自動增加寄送權限。重置包含假資料版本與本地狀態，不包含修改全域設定。
