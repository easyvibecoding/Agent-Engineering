# C01 · 分級提示

先完成自己的答案。第一級只提示方向，仍卡住再看第二級。

<a id="c01-q01"></a>

## C01-Q01

1. 先找出需要真的接觸檔案或改狀態的工作。
2. 計算可用確定性程式；提出動作不代表有權執行。

[回題目](README.md#c01-q01)

<a id="c01-q02"></a>

## C01-Q02

1. 比較規則是否已列完整。
2. 若所有資料與分支都固定，客服流程也能先用規則。

[回題目](README.md#c01-q02)

<a id="c01-q03"></a>

## C01-Q03

1. 區分寫完文字和真的寄出。
2. 沒有寄信紀錄時，先不要說已寄送。

[回題目](README.md#c01-q03)

<a id="c01-q04"></a>

## C01-Q04

1. 不要只畫使用者接模型。
2. 把核准和完成證據放到模型之外。

[回題目](README.md#c01-q04)

<a id="c01-q05"></a>

## C01-Q05

1. 從模型外面的實際工作回答。
2. 即使判斷正確，檔案、權限與停止仍要有人管。

[回題目](README.md#c01-q05)

<a id="c01-q06"></a>

## C01-Q06

1. 先寫一個成功結果長什麼樣子。
2. 日期符合但缺拆封資料也要有可驗收回答。

[回題目](README.md#c01-q06)
