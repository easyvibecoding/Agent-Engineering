# 14 · 系統設計、案例整合與面試

章節 ID：C14 · 內容修訂：2026-10-21 · 核心約 2–3 小時 · Lab 僅規格，尚未實作。

<a id="這章要交出什麼"></a>

## 先開始，不用先畫完整架構

面試官問「你會怎麼做客服 Agent？」你有很多名詞，卻接不出第一句。先開[正文](lesson.md)，跟著四個場景練：先縮需求，讀對資料，再說誰擋住錯誤，最後交代怎樣算完成。

第一次讀可以略過深挖區的一頁大表、事件表和完整流程圖。先做到 Q01 或口答 Q05，就可以留下接讀紀錄；有問題再回相對場景，不必從章首重讀。

## 具體前置與跳章入口

你需要分得清三件事：來源是否支持結論；模型提議與工具實際執行；一輪完成與業務完成。陌生可回看第 [03](../../agent-core/03-tool-contracts/lesson.md)、[07](../../codex-runtime/07-codex-runtime/lesson.md)、[13](../../production/13-evals-observability-and-budgets/lesson.md) 章相關段落，不必先做完練習。

共用合成案例：T-1042 r3，2026-10-08 買、10/20 申請，相差 12 天。D14 自 10/01 取代 D07，要求 ≤14 天且未拆封；r3 包裝未知。只判斷與草稿，不寄送、關單或退款。詳見[共同案例](../../../maps/course-story.md)。

<a id="核心讀法一天完成"></a>

## 核心讀法：一次只完成一段

1. 先讀正文四個場景；看到微停頓，先選或寫一句，再看下一段。
2. 做 [Q01](exercises/README.md#c14-q01)，或先用[面試卡](interview.md)講兩分鐘。先留原答，不求第一版完整。
3. 14 天路線再做 Q03；7 天路線可先停在 Q01、Q05。卡住先回正文相對場景，再按需讀[提示](exercises/hints.md)。
4. 想檢查理由時才開[設計取捨](design-notes.md)；要求解答時才看[參考解答](exercises/solutions.md)。

核心可分數段完成，總計約 2–3 小時。中斷前填正文最後三格：已知、疑問、下一步。

## 深挖讀法：另排時間

讀正文「轉移到其他任務」與「第 15–28 天」，完成 Q02、Q04、Q06。用[Codex 協作卡](codex.md)逐步追問，再審[未來 Lab 契約](lab/README.md)。這一層仍是抽象教學，不建立程式或環境。

## 自我驗收

能用 T-1042 r3 解釋：12 天符合但完整資格未知；只讀流程如何走、何時停；四個風險各由誰負責並如何測；何時才增加檢索、多 Agent 或寫入。只背元件名詞，回正文的資料路徑重做。
