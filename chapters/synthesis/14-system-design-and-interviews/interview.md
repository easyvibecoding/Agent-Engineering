# C14 · 面試與追問

## 主問題

用兩分鐘回答：你會如何打造可靠的客服 Agent？

先口答兩分鐘：用一句話定義問題，再引用本章資料說明決策、失敗與驗收。不要逐字背參考解答。

## 面試官可以怎麼追

- 方案選擇：比較單一 Agent 與多 Agent 方案，何時值得改成後者？
- 出錯定位：設計稿寫 r3 包裝未知但已核准退貨，並用 turn/completed 證明已退款。逐項修正。
- 設計落地：完成一頁架構，把每個元件對應到一個失敗與驗收。

## 自評

每項 0–2 分：是否答到需求；是否引用具體資料；是否說明取捨與限制；是否提出可觀察驗收。0 為缺少，1 為只有概念，2 為能用案例說明。分數只供練習，不代表已通過真實面試。

本題重點：先需求，再流程、失敗、驗收與取捨。

先自評，再按需看[Q05 參考解答](exercises/solutions.md#c14-q05)。涉及執行成果時，分開說已設計、已實作、已測試；本 repo 的 lab 尚未實作。
